# img2drawing v1.4.0

Release date: 2026-11-27
Release scope: **Multi-Medium Drawing**
Default renderer: **img2drawing-pencil / 11**

## Drawing tools

New sessions may explicitly select `RenderProfile.mixed_media(...)`:

- G-pen and fineliner paths, explicit width/pressure intent, point tapers and supported cap/join styles.
- Wet ink brush, explicitly closed solid contours with optional authored holes, and opaque white paint.
- Editable analytic dot screentone with coverage, pitch, angle, page-fixed phase and optional authored linear gradient.
- Same-ID replacement, retirement, guarded preview/apply and supported ink transforms through the existing ordered action history.

The default mixed selection is `mixed-media-v3`; `screentones=False` selects v2 and `styled_paths=False` selects v1. Each selection has its own immutable renderer contract digest. The default pencil v11 and existing normalized graphite v1/v2/v3 contracts remain unchanged. Existing sessions are not automatically migrated.

The agent authors all geometry, boundaries, holes and tone decisions. This release does not add tracing, source masks, automatic region selection, a separate manga session or a second renderer/exporter. White ink covers lower marks; it is not alpha erasure. Graphite lifting remains material-selective.

## Replay and package behavior

Incremental mixed-history validation, conservative contour intersection checks, and exact bit-packed ink patch caching reduce repeated work without changing the render contracts. Opaque ink-only histories can use the verified incremental Fast path; mixed-media histories containing graphite or eraser actions, transparent backgrounds and unsupported combinations retain canonical replay. The cache's 32 MiB limit covers retained packed payload, not total process memory or temporary raster allocations.

The standalone skill ZIP includes the conditional mixed-media guides and executable public API example. Wheel, sdist and skill ZIP retain the existing source/private-data boundary. S06e also fixes Fast replay under Pillow 13 for both ink and legacy graphite: Pillow 13+ or unknown versions downsample the incrementally composed canvas at canonical page dimensions; pre-13 versions retain the verified guarded crop optimization. Patch caching and dirty delta writes remain. This avoids crop-dependent resampling differences without changing canonical drawing kernels, persisted profiles or equality/GIF tolerances. Pure legacy graphite Fast remains supported. Full-page downsampling has a measured performance cost; no universal speedup is claimed.
