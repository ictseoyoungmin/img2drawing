# img2drawing v1.1.0

Release date: 2026-09-27  
Release slice: **R1 structural refactor**  
Current renderer: **img2drawing-pencil / 11**

v1.1.0 reorganizes the public implementation around one session, one renderer, and one timelapse exporter. The v11 golden covers direct renders and session final, cursor, inspection, fast, and canonical timelapse output; rendered pixels match v1.0.3 for that contract.

## Changes

- `img2drawing.session` owns `DrawingSession` and session records; `img2drawing.authoring` owns markmaking, retune, curve sampling, and construction helpers. The package-root `DrawingSession` entry point remains available.
- `img2drawing.render` replaces the generation-layered renderer modules and uses the persisted family identity `img2drawing-pencil / 11`.
- `RenderProfile` v2 records a renderer contract digest. A foreign digest or unknown renderer fails closed instead of claiming exact replay.
- `img2drawing.timelapse` provides one exporter behind `DrawingSession.export_timelapse()`. The method adds `backend`, `fps`, `materialize_frames`, and `cache_dir`; the export manifest advances to v2.
- Rendering a broad stroke clipped fully outside the canvas no longer raises `Operation on closed image`.

## Compatibility

The `img2drawing.vnext` and `img2drawing.provenance` import namespaces, older compatibility shims, v9/v10 runtime renderer implementations, and region-fill replay are removed. Code importing those paths must move to the current package root or owning namespace. Exact replay of v9/v10 or retired region-fill sessions requires `img2drawing==1.0.3`. The v1.0.3 v11 profile without a digest remains accepted because the v11 golden proves pixel identity. Profile-less checkpoints require an explicit `migrate_render_profile()` before rendering.

Persisted `img2drawing.vnext.*` session schema strings remain data identifiers; they are not import paths.
