# img2drawing v1.3.0

Release date: 2026-11-27
Release scope: **Constructive Drawing**
Default renderer: **img2drawing-pencil / 11**

- Explicit landmark, proportion, occlusion and projected-volume tools for observation and construction.
- Editable curves, pressure/contact-width control, local erasure and atomic stroke/group corrections with previews.
- More focused portrait, hair, anatomy and fabric guidance, plus tonal/overlap inspection.
- Optional normalized graphite profiles, safer action validation, compact GIF export and a standalone skill ZIP.

The legacy v11 renderer pixels and stored render identities remain unchanged; the optional normalized material contracts require explicit selection. Existing sessions retain their saved profiles. No automatic tracing, fill generation or new renderer engine.

Validation: [PR #104 CI](https://github.com/ictseoyoungmin/img2drawing/actions/runs/45868789654) passed 473 active tests and 44 focused runtime checks, including package/install, golden replay and instruction graph checks. Publication requires green CI on the promoted main commit. The maintainer selected this bounded release without claiming independent six-class artistic improvement; that comparison and extended high-resolution long-session performance remain unverified and are follow-up research. Existing historical releases remain immutable.
