# img2drawing v1.2.0

Release date: 2026-10-28
Release slice: **M02 portrait authoring, stroke reshape and streaming GIF fidelity recovery**
Current renderer: **img2drawing-pencil / 11**

v1.2.0 extends the v1.1.1 authoring and replay workflow with **no renderer v11 pixel or persisted drawing-schema changes**. This is a correction/provenance/output-fidelity release, not a claim of fresh portrait-likeness or peak-RSS visual validation.

## Changes

- Whole-head and enlarged-face comparison for identity-sensitive portraits, observed eyes/nose/mouth/jaw relationships, upstream correction before facial detail, selective observed croquis value for hair, clothing and face.
- Public `img2drawing.authoring.reshape_stroke` preserves role, part, layer, tool/grade, authored pressure and previous global/local erasure effects where representable, returning a correction action ID for residual closure.
- Replay exports report required pixel work before touching output and offer progress callbacks across render/encode/verify/retry phases.
- GIF palette fidelity failure can be retried with **local palettes streamed one frame at a time** from the original delta pack. No all-frame in-memory list or temporary PNG sequence; canonical GIF writing also streams.
- The final GIF hash is consistent between authoritative manifest fields. Failed FFmpeg attempts are identified separately, retry time is counted, and fidelity thresholds remain unchanged.
- Project handoff captures the scripts, session checkpoint, reference, environment, outputs and replay manifest.

## Compatibility and evidence

- Renderer `img2drawing-pencil / 11`, contract digest and v11 goldens remain unchanged. Historical v9/v10 or region-fill replay continues to require `img2drawing==1.0.3`.
- PR #75 passed **264 active tests** and **44 package-boundary tests**, with green push and PR CI after recovery fixes. Main CI must pass for the publication workflow to create the release.
- The S03 quality decision remains **PASS / USER_ACCEPTED**; four class-level runs are **NOT_RUN**. Fresh independent portrait likeness and long 2048×2048 peak-RSS tests are **NOT_RUN**; they are not implied by code-level CI success.
- Separately identified broad-graphite partial override/provenance loss and oversized tonal strokes belong to follow-on **v1.2.1** development, not this release.
