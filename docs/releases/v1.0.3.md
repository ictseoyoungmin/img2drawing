# img2drawing v1.0.3

Release date: 2026-09-13
Release revision: **A14**
Public API: **DrawingSession/1.0.3-vnext**
Current renderer for new sessions: **pillow-pencil-contact-v11 / 1**

v1.0.3 is the post-v1.0.2 quality/integration release. It promotes the renderer and gesture work validated across the rc1–rc3 cycle while preserving explicit historical replay for older renderer identities.

## Highlights

### Gesture is a real public drawing mode

`DrawingIntent(drawing_mode="gesture")` is supported by the runtime. Unqualified gesture work uses the instruction graph's constructive-gesture default, while explicit pure/quick gesture remains a finish-level choice rather than a hidden workflow stage.

Gesture guidance now rejects both common abstraction failures:

- geometric stock icons such as circle-heads, boxes, flat polygons, and faceted ribcage/pelvis masses;
- the opposite over-correction into generic bean/oval/capsule blobs.

Sparse gesture marks should preserve observed facing, jaw/profile direction, shoulder/back/side asymmetry, hip shelf and leg attachment, support, major limb chains, negative spaces, and decisive prop/body anchors.

### Broad pencil material is more physical

New sessions use renderer `pillow-pencil-contact-v11 / 1`.

Compared with v10, v11:

- keeps ordinary thin strokes byte-identical to v10;
- replaces visible broad continuity-core butt/square terminal cuts with pressure/taper-resolved round physical contact;
- strengthens deterministic page-fixed graphite/tooth variation in broad marks;
- mean-normalizes the added material variation so the renderer does not silently re-author average value;
- keeps canonical final and fast timelapse on the same registered patch builder.

Explicit v9/1 and v10/1 renderer identities remain available for historical replay.

### Renderer/replay identity is explicit

The canonical RenderProfile for new v1.0.3 sessions selects v11. Existing checkpoints persist their renderer id/version and resume through that renderer instead of silently migrating pixels.

The v1.0.2 v9 authority remains frozen. v10 remains explicit rc1/rc2 replay authority. v11 is additive rather than an in-place rewrite.

### Completion/evidence contracts are stricter

`DrawingSession.finish()` now refuses to close a blank/fully-erased current canvas and requires a non-stale final inspection evidence-read event. `accepted_limitations` records acknowledged non-blocking weakness; it does not bypass unresolved residual records.

Residual/correction guidance also makes the originating `observation_id` provenance contract explicit.

### Retired R23 runtime is physically gone

The installable `img2drawing.legacy.r23` namespace and the old R23 orchestration/runtime cluster are removed from current `src`. Historical source/release evidence remains available from Git history and `dev/legacy/` records.

Deprecated pre-0.6.0rc2 root compatibility shims for still-owned capabilities remain available but undiscoverable from the normal root API; removing them is a separate future compatibility decision.

## Validation

### Gesture dogfood

G01 fresh-worker dogfood exercised both explicit pure gesture and unqualified gesture/constructive behavior. It found and closed runtime-mode, primitive-shape, anti-blob, and semantic-mark/tool-adapter integration gaps.

Evidence: `dev/dogfood/g01-gesture-rc2/README.md`.

### Broad-pencil dogfood

G02 reproduced the user-observed square-terminal/weak-graphite defect under both drawing-scale and 9–14 px high-pressure stress passes. v11 visibly rounded the broad endpoints and increased local graphite/tooth variation without obvious global value drift.

Evidence: `dev/dogfood/g02-broad-pencil-v11/README.md`.

### Mechanical renderer gates

The active suite verifies:

- v10↔v11 ordinary 2 px thin pixel exactness;
- broad terminal morphology improvement at transitional width;
- stronger broad graphite/tooth local variation within authored-value tolerance;
- explicit v9 and v10 replay after v11 becomes current;
- v11 canonical-final ↔ fast-final pixel exactness, including late lower-layer dirty recomposition;
- material-policy differentiation under v11.

The immutable v1.0.2 rendering/export bytes and B18 release history continue to pass their historical gates.

## Compatibility notes

v1.0.3 contains compatibility changes relative to v1.0.2:

- the retired R23 runtime/legacy namespace is no longer installable;
- `finish()` now raises on blank/fully-erased drawings and stale/unread final inspection evidence where earlier versions could return a FinishRecord;
- new sessions select renderer v11 rather than v9/v10.

Persisted explicit renderer identities remain replayable; v1.0.3 does not rewrite the pixels of saved v9/v10 sessions.
