# img2drawing v1.0.3rc1 release-candidate notes

Status: **release candidate, not published stable**

Package identity: **1.0.3rc1**  
Public contract identity: `DrawingSession/1.0.3-vnext`  
Release revision: **A11**  
Release slice: `v1.0.3rc1_renderer_v10_markmaking_rc`

The latest published stable release remains **v1.0.2**. No `dev/release/publish/v1.0.3rc1.json` manifest exists; this candidate must not be published by the stable release workflow until an explicit promotion decision creates one.

## Candidate changes

### Renderer v10

- New sessions resolve to `pillow-pencil-contact-v10 / 1` while explicit historical v9 sessions remain on the frozen v9 backend.
- v10 removes private compatibility `Stroke.stage` from hand-dynamics seed identity so inspect/current-state, canonical final/replay, and the fast timelapse path agree for identical authored geometry.
- Broad graphite uses an authored-value core plus a material shoulder: pressure/opacity authority is preserved in the core while tooth, dry breakup, and radial contact remain visible outside it.
- Ordinary thin strokes retain the optimized thin path; broad and flick behavior use the v10 material/contact path.

### Markmaking runtime and instruction graph

- Renderer contracts/registry/dispatch are explicit runtime authorities rather than direct renderer imports.
- Style/tool vocabulary includes `canonical-pencil`, `manga-light`, and `dry-graphite-expressive` plus role/tool selection guidance under the `markmaking/` instruction-graph branch.
- Cache/provenance identity includes renderer identity/contract and resolved markmaking state required for exact replay.
- Late low-layer strokes trigger layer-order-aware dirty recomposition instead of being appended above later layers.

### Compatibility

- v9 remains the historical replay authority for saved v1.0.2 sessions; v10 does not silently rewrite them.
- The immutable v1.0.2/A10 `CONTRACT_FREEZE.json`, release notes, and publish manifest remain unchanged.
- Post-v1.0.2 source cleanup and stricter `finish()` evidence requirements remain compatibility-impacting changes already documented in `CHANGELOG.md`.
- Deprecated pre-0.6.0rc2 root shims remain supported in this RC; their retirement is a separate compatibility decision.

## Promotion evidence

The candidate was benchmarked from the exact GitHub Actions wheel on the 1,272-action `window-study` fixture with authored stroke widths scaled ×3. Same-environment three-trial medians were used because absolute timing differs across execution slots.

| width×3 render+pack | v9 median | v10 median | v10 delta |
|---|---:|---:|---:|
| cold | 27.389 s | 28.727 s | **+4.886%** |
| warm | 10.062 s | 10.199 s | **+1.365%** |
| cold patch build | 16.247 s | 18.206 s | **+12.058%** |

Final RGB authority under the same fixture:

- v9 fast = v9 canonical: `3cbbce01c35cdad0acfb852e5f06bfe67d05a0e7f7e4b8e2eacb7c6d2b0e9aca`
- v10 fast = v10 canonical: `72aa16996a6ce5ec8db672782e7ab1487f5593aae77afbe2769b4396c4842205`

The v9 and v10 outputs are intentionally not required to equal each other; each renderer's fast path must equal its own canonical authority.
