# img2drawing v1.1.1

Release date: 2026-09-29  
Release slice: **M01 public contract coherence + release hygiene**  
Current renderer: **img2drawing-pencil / 11**

v1.1.1 is a maintenance release over v1.1.0. It closes public-contract and release-tooling drift discovered after the structural release without changing renderer pixels, persisted drawing schemas, or the v11 replay contract.

## Changes

- Codex and Claude plugin manifests now follow the Python package version, with CI comparing them directly to `img2drawing.__version__`.
- Runtime capability discovery separates `authoring_operations` from `output_operations` and exposes `supported_operations` as their combined worker-facing view. The old `supported_authoring_operations` attribute remains a compatibility alias for callers that consumed the v1.1.0 surface.
- Exact authoring entrypoints remain explicit: `DrawingSession.draw`, `replace_stroke`, `soft_lift`, and `delete_stroke`.
- Residual correction binding requires exact observation ownership; `soft_lift()` and `delete_stroke()` also require an explicit reason before they can close a residual.
- The semantic markmaking resolver accepts the explicit `value` role used by stroke-authored tonal work.
- `InitialConstruct.to_dict()` preserves authored pressure, tool, grade, and tool overrides.
- Inspection documentation now matches the implemented evidence raster policy: persisted material/renderer authority, 1× output geometry, and default 3× inspection supersampling.
- Current release verification is version-generic instead of hard-coding the v1.0.3→v1.1.0 transition.
- The current package/supply-chain verifier now has a semantic filename, stale current-test filenames were cleaned up, and retired v1.0.3 branch-only build/upload steps were removed from active CI.

## Compatibility

The renderer remains `img2drawing-pencil / 11` with the same contract digest and v11 golden pixels as v1.1.0. No persisted drawing/session schema changes in this release. The package-root API remains unchanged.

Persisted `img2drawing.vnext.*` identifiers remain compatibility data, not import paths. Exact replay of v9/v10 or retired region-fill sessions still belongs to `img2drawing==1.0.3`.

## Validation and scope

The release gate covers the v11 golden, current runtime surface, active tests, instruction graph, historical v1.0.2/v1.0.3/v1.1.0 authority, package build/clean-install checks, plugin metadata, and generic current-release documentation consistency.

The S03 visual dogfood decision remains **PASS / USER_ACCEPTED**. The four prepared still-life class runs remain `NOT_RUN`; v1.1.1 does not convert that acceptance into a measured class-level visual-quality claim.

The additive contract freeze is `dev/release/vnext/CONTRACT_FREEZE_V1_1_1.json` and is attached as a release asset. Earlier release tags, wheels, manifests, notes, and freezes remain immutable.
