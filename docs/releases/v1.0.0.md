# img2drawing v1.0.0

The first stable img2drawing release publishes the A8-aligned stage-free drawing system without
adding new drawing/runtime behavior after the successful GPT-6 Astra demonstration.

![Reference versus drawing](https://raw.githubusercontent.com/ictseoyoungmin/img2drawing/v1.0.0/showcase/entries/croquis-sniper-girl-astra-v1/ref-vs-drawing.jpg)

![End-to-end timelapse](https://raw.githubusercontent.com/ictseoyoungmin/img2drawing/v1.0.0/showcase/entries/croquis-sniper-girl-astra-v1/timelapse.gif)

## Stable baseline

- Package: **1.0.0**
- Public contract: `DrawingSession/1.0.0-vnext`
- Instruction graph: A8-aligned
- One canonical stage-free `DrawingSession` route
- Explicit authored strokes and history-safe replacement/deletion
- Observed / imaginative / hybrid authority on the same session core
- Canonical pencil-contact rendering, deterministic replay, and PNG/GIF provenance
- R23 retained only behind the explicit legacy compatibility boundary

## Astra capability demonstration

A GPT-6 Astra worker completed a detailed observed croquis with no image generation, raster
tracing, broad fill, or `fill_region` actions.

- 490 total actions
- 358 stroke additions
- 120 replacements
- 12 deletions
- 0 fill actions
- 124-frame end-to-end replay sampled every 4 actions from cursor 0 through 490
- canonical final PNG exactly matched the replay final PNG
- decoded canonical GIF final-frame maximum channel error: 1

The result preserves whole-body orientation, face/torso counter-turn, asymmetric stance and hair,
unequal boot directions, rifle/body depth, and identity-bearing face/clothing/prop details.

The curated entry is available at:
https://github.com/ictseoyoungmin/img2drawing/tree/v1.0.0/showcase/entries/croquis-sniper-girl-astra-v1

## Claim boundary

v1.0.0 is intentionally a **bounded stable baseline**, not a claim that every worker or subject
reaches the Astra result. Formal D01-D06 sealed cross-subject/cross-agent validation has not been
completed. The Astra subject-specific scripts, coordinates, and control-point notes are not shipped
as examples or worker inputs.

Mechanical CI verifies package/API/persistence/replay contracts; it does not produce an automatic
artistic-quality PASS.

## Next: v1.0.1

The next patch release will absorb only generalized, evidence-backed authoring lessons from the
Astra run. Current candidates include geometry-preserving stroke retuning, shared curve sampling,
continuous-edge pencil handling, and stronger reusable authoring/correction ergonomics. No
subject-specific answer geometry will be copied into the skill.
