# img2drawing v1.0.3rc3 candidate notes

Date: 2026-09-13  
Package identity: **1.0.3rc3**  
Public contract identity: `DrawingSession/1.0.3-vnext`  
Release revision: **A13**  
Release slice: `v1.0.3rc3_broad_pencil_material`

The latest published stable release remains **v1.0.2**. No `dev/release/publish/v1.0.3rc3.json` manifest is created by this candidate.

## Purpose

RC3 is a focused renderer/material follow-up to the rc2 gesture candidate. Broad-pencil dogfood exposed two defects that were easy to miss in thin-line work:

- transitional broad strokes could expose a high-alpha square/butt continuity-core terminal;
- broad interiors could read too uniformly, weakening the expected graphite/paper-tooth character.

## Renderer v11

New sessions select `pillow-pencil-contact-v11 / 1`. Renderer semantics are additive and immutable:

- explicit v9/1 remains the v1.0.2 historical replay authority;
- explicit v10/1 remains available for rc1/rc2 replay;
- v11 delegates ordinary thin strokes byte-for-byte to v10;
- v11 preserves the v10 radial shoulder and authored-value model for broad marks;
- broad continuity-core terminals use pressure/taper-resolved round physical contact instead of a visible butt cut;
- broad graphite/tooth modulation is stronger and page-fixed, but mean-normalized so material texture does not silently re-author average value.

## Required promotion evidence

RC3 is not stable-promotion authority until all of the following are green:

- deterministic v10 failure reproduction;
- v10↔v11 ordinary-thin pixel exactness;
- broad terminal morphology regression gate;
- broad graphite/tooth variation gate with authored-value tolerance;
- v11 canonical final ↔ fast timelapse pixel exactness;
- full active tests, historical evidence, package/installed-API audit, and frozen v1.0.2 history verification;
- reviewed broad-pencil visual comparison.

The existing rc1 width×3 performance/parity evidence remains historical evidence for v10; changed v11 bytes require fresh evidence before stable v1.0.3 can be declared.
