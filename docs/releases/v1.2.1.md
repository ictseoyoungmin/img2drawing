# img2drawing v1.2.1

Release date: 2026-11-26
Release slice: **M03 tonal authoring and provenance maintenance**
Current renderer: **img2drawing-pencil / 11**

This is a bounded maintenance and diagnostic release, selected by the maintainer on 2026-11-26. It preserves renderer pixels and the existing session/action/replay schemas. It is not a release claim of improved independent portrait likeness.

## Changes

- Merge per-call partial tool overrides into the resolved material state, preserving untouched hardness, grain and other material fields; reconcile provenance to the actual executed ToolState and reject conflicting intent before mutation.
- Add explicit `TonalAreaPlan` / `TONAL_AREA_SCHEMA` planning metadata for authored polygons, direction, density, value, pressure and reserved light. The plan never generates or fills strokes.
- Clarify authored tonal overdraw and protected light in the skill guidance.
- Developer-only QA: controlled graphite swatches, isolated high-resolution replay stress tests and real-session tonal-plan cursor interval diagnostics. These tools measure paper-relative coverage, saturation, protected areas and darkness deltas without mutating drawing history. They are not included in the deployable runtime package.
