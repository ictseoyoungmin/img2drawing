# Subjectless mechanical example

This example uses imaginative `ReferenceAuthority` and drawing-only inspection. It never
creates a fake subject, registration, overlay, or subject-space measurement.

```bash
python examples/subjectless/run.py --output /tmp/img2drawing-subjectless
```

It exercises the same correction, finish, replay, and resume core as observed work and
makes no claim of artistic quality.
