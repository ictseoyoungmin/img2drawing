# Legacy R23 stage references

This directory contains R23 compatibility material referenced by
`references/legacy-r23.md`. Do not include it in the reading route for new work.

The `p1-*` through `p6-*` files, `stage-contracts.md`, and bundled images preserve
the stage-oriented representation vocabulary and regression evidence of the
existing `DrawingRun`. Do not reuse the Pn, stage, advance, or reopen semantics in
these files as a vNext API, mode, or finish lifecycle.
