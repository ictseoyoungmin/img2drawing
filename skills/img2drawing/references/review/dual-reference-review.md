# Two questions, two authorities
Geometry and stage grammar answer different questions.

- Subject: Where is the body? What carries weight? What overlaps what?
- Frozen `StageContract` + the current stage reference: What information belongs in this
  stage? How economical should the marks be?
- Drawing: What did the Agent actually commit?

A stage can match the subject yet still be a poor P1/P2/P3 representation; it can also look
like a textbook stage drawing while carrying the wrong pose. Review both separately.

Some stage references keep a rendered example image beside them. Open one when it would
answer a concrete question about mark-making. It is an illustration of the contract, never
a second authority, and never a source of pose or coordinates.
