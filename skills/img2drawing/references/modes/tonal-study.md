# Tonal study

A tonal study organizes large light/dark families while preserving the geometry that makes
those value regions meaningful.

Read the large value grouping first. Reserve lights deliberately inside darker regions,
and keep edges consistent with observed form and material. Do not use noisy hatching to
hide incorrect silhouette, overlap, or anatomy.

Tone supports structure; it does not replace it. Resolve major geometry before committing
to dense value work.
