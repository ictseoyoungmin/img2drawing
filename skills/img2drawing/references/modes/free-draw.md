# Free-draw mode

free-draw는 규칙 없음이 아니라 reference authority가 다를 수 있는 intent-led
작업이다.

## Intent first

작업 시작 전에 최소한의 목적을 선언한다. 예: expressive character sketch, creature
silhouette study, environment thumbnail, abstract line rhythm. reference가 없으면
overlay·registration·plumb를 억지로 만들지 않는다.

## Suggested grammar

```text
declare intent → draw a hypothesis → inspect composition/rhythm/focal
→ name residual → correct explicit strokes → repeat → finish
```

imaginative 작업은 intent와 drawing의 mismatch를, hybrid 작업은 보존할 reference
constraint와 변형하려는 intent를 함께 본다. runtime이 artistic judgement를 자동으로
대신하지 않는다.

## Completion questions

composition, shape rhythm, focal hierarchy, declared style/energy가 의도와 일치하는가?
reference가 없다는 이유로 residual loop를 생략하지 않으며, 반대로 subject overlay를
가짜 authority로 만들지도 않는다.
