# Free draw

Free draw uses declared imaginative goals rather than an observed subject. Establish a
clear composition, dominant shapes, spatial relations, and material/line intent before
refinement.

The absence of a reference does not remove the need for consistency. Preserve the declared
pose, proportions, topology, perspective, contact, and silhouette unless intentionally
revised. Use the same construct → inspect → residual → correct loop, with drawing-only
evidence and no fabricated reference claims.
