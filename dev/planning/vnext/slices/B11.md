# B11 — Canonical RenderProfile, replay, and GIF parity

State: **ACTIVE**
Depends: B10

## Goal

Bind final PNG, replay, and timelapse to one canonical rendering configuration and one
authoritative history so process export cannot silently drift from final output.

## Separation of concerns

```text
StyleGuide    = how the Agent authors marks
RenderProfile = how authored marks are materialized/rasterized
```

Never merge the two. Changing `RenderProfile` may change raster appearance but must not
rewrite geometry/history or pretend to be an authoring style change.

## Deliverables

- versioned `RenderProfile` contract covering at least:
  - renderer id/version;
  - canvas size;
  - pencil/material profile;
  - paper/grain;
  - supersampling;
  - deterministic seed domain;
  - compositing;
  - encoding/output policy;
- canonical vNext cursor replay from action 0 to latest;
- end-to-end GIF export using the same renderer/profile as canonical PNG;
- explicit sampling/timing semantics including `every_n` support;
- parity manifests and deterministic regression fixtures;
- explicit unsupported/migration behavior for old renderer/profile metadata;
- B11 capsule and status transition to B12.

## Value-region replay

One authored `fill_region`/`replace_fill_region` action may deterministically materialize
many hatch contacts. Timelapse must treat that as one authored decision, not hundreds of
fake authoring frames. Frame timing may hold longer for such region decisions, but replay
must remain derived from the authoritative action history.

## Definition of Closed

- [ ] A history with more than one authored action yields more than one meaningful GIF
      frame.
- [ ] Action 0 / initial state and latest state are included under documented semantics.
- [ ] Final GIF frame and canonical final render are pixel-equivalent under the same
      profile, or meet one documented encoded-color tolerance.
- [ ] Replay/resume are deterministic for the same history/profile/version.
- [ ] Silent canvas, supersample, material, seed, compositing, or renderer-version drift
      is rejected.
- [ ] `fill_region` produces deterministic raster output without exploding into authored
      action frames.
- [ ] Existing pencil-contact renderer remains single-source; no geometry mutation occurs
      in output code.
- [ ] Performance/size budget and artifact provenance are regression tested.
- [ ] No fresh visual dogfood is used for closure; D01–D05 will exercise real outputs
      after B18.
- [ ] Capsule/docs/tests complete and B12 is next sole WIP.

## Non-goals

Large brush catalogs, charcoal/ink families without later evidence, artistic quality
scoring, and fresh dogfood.
