# B07 — Evidence and cost control

State: **CLOSED**
Depends: B06

Activated: **2026-08-31** as the sole production WIP after B06 closure. The slice is
limited to evidence selection/cost telemetry over the existing `DrawingSession` and
`InspectionSheet`; no second inspection implementation or B08 intent/mode schema is
allowed.

## Goal

Keep the correction loop visually trustworthy while preventing review machinery from
outgrowing drawing work.

## Deliverables

- one `InspectionSheet` default with whole view and at most 1–3 prioritized ROIs;
- optional measurement escalation rules for grid, plumb, angle, distance, profiles,
  negative space, and pixel samples;
- lightweight telemetry for image reads, generated artifacts, review turns, and elapsed
  work without artistic scoring;
- comparison against the legacy multi-packet/manifest workflow.

## Definition of Closed

- [x] Representative correction reaches equal or better directly reviewed quality with
      materially fewer directly comparable image reads/review ceremonies than the R23
      baseline; generated-file inventories are reported separately.
- [x] Default loop uses one sheet; extra ROI/measurement evidence has a recorded reason.
- [x] Earlier immutable evidence and subject/state/hash binding remain intact.
- [x] Missing or unreadable evidence fails visibly; telemetry never produces PASS.
- [x] No second inspection implementation or manifest-builder abstraction exists.
- [x] Performance/cost observations, tests, direct review, and capsule are recorded.

## Narrow reclosure record

ROI/guide/grid/measurement extras; focused requires 1–3 ROIs and rejects guide/grid/
measurement extras; deep allows up to 3 ROIs with guide/grid/measurement evidence and

authored guides or grid select deep mode. The policy is documented as a presentation/read
budget because the existing renderer still writes its six authoritative artifacts.

R2 adds resume-time cross-validation for every persisted `EvidenceReadRecord`: the
inspection ID must exist, its historical drawing hash must equal the matching inspection
record, and its canonical artifact key must be present in that immutable manifest. New

the B07 direct sheets or correction geometry. B07 is closed again; B08 remains the next
slice and is not activated here.

## Handoff to B08

B08 may introduce the disposable `DrawingIntent`/mode/style scaffolding while reusing
this single inspection and telemetry boundary. Do not turn evidence modes into stages,
add automatic ROI selection, or add artistic acceptance metrics.

## Activation contract

- Default `DrawingSession.inspect()` remains one tiled `InspectionSheet` with whole view
  and no extra evidence in quick mode. Focused explicitly accepts 1–3 Agent-selected
  ROIs; no automatic ROI selector is introduced.
- `quick`, `focused`, and `deep` are evidence presentation budgets, not lifecycle stages.
  Deep mode is opt-in and requires a human-readable escalation reason when it adds ROIs,
  guides, or measurements.
- Telemetry records observable reads/artifacts/review turns/elapsed work only. It never
  emits artistic PASS/FAIL, changes drawing geometry, or chooses residual priority.
- B07 compares one representative B06 correction against the legacy multi-packet review
  ceremony using committed, reproducible counts rather than quality scoring.

Risks to close:

- a compact quick sheet could hide a useful mismatch;
- evidence escalation could silently become a new stage machine;
- telemetry could be mistaken for artistic acceptance or introduce duplicate manifests.

## Non-goals

Mode/style schemas, automatic ROI selection as authority, and release-wide package
cleanup are outside this slice.


## Second reopen — B07-R1 canonical session compaction

Reopened and closed: **2026-08-31**.

The first B07 closure controlled *evidence* cost (how many images the agent looks at)
and that layer held: the triggering dogfood spent 18 inspections and 1 image read, 110
lines of session. What it did not control was the cost of the drawing record itself.

### Evidence

| | R23 baseline | post-B08 dogfood |
|---|---|---|
| canonical session | 39,866 lines | 313,391 lines |
| hand-authored strokes | 394 | 386 |
| machine hatch-fill strokes | 0 | 1,398 |
| points per stroke | 3.7 | 21.0 |
| lines per stored point | 21.8 | 8.2 |

The record format was not the regression; the absence of a value primitive was.

### Added to Definition of Closed

- [x] A value region is one authored action, not one per hatch line.
- [x] Deposition calibration is cached out of session and regenerated by a script; no
      drawing session probes the renderer to find a working opacity.
- [x] A light inside a dark mass is reserved by the fill, not erased back out.
- [x] `tool_state` is recorded once per action; derived pressure is recomputed on load;
      explicitly authored pressure is preserved verbatim; older sessions still load.
- [x] A rendered fill lands within ~20 levels of its requested value, checked on canvas
      rather than in the table.

### Deliberately not done

Splitting canonical provenance from a raw debug trace. The measurement gave it a 1.3%
ceiling here, and freezing a second file format before a fresh dogfood would cost more
than it saves. Revisit only if a post-B07-R1 session still grows without a named cause.
