# B07 — Evidence and cost control

State: **SKELETON**
Depends: B06

## Goal

Keep the correction loop visually trustworthy while preventing review machinery from
outgrowing drawing work.

## Deliverables

- one `InspectionSheet` default with whole view and at most 1–3 prioritized ROIs;
- optional measurement escalation rules for grid, plumb, angle, distance, profiles,
  negative space, and pixel samples;
- lightweight telemetry for image reads, generated artifacts, review turns, and elapsed
  work without artistic scoring;
- comparison against the legacy multi-packet/manifest workflow.

## Definition of Closed

- [ ] Representative correction reaches equal or better directly reviewed quality with
      materially fewer image reads/artifacts/review ceremonies than the R23 baseline.
- [ ] Default loop uses one sheet; extra ROI/measurement evidence has a recorded reason.
- [ ] Earlier immutable evidence and subject/state/hash binding remain intact.
- [ ] Missing or unreadable evidence fails visibly; telemetry never produces PASS.
- [ ] No second inspection implementation or manifest-builder abstraction exists.
- [ ] Performance/cost observations, tests, direct review, and capsule are recorded.

## Non-goals

Mode/style schemas, automatic ROI selection as authority, and release-wide package
cleanup are outside this slice.
