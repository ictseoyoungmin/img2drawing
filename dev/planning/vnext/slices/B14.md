# B14 — Drawing-mode capability completion

State: **CLOSED**
Depends: B13

## Goal

Complete the smallest useful drawing-mode authoring surface on one shared core. This
slice implements mode capability; it does **not** run the old M1–M6 dogfood matrix.
Full mode-quality validation moves to D01–D05 after B18.

## Target mode set

Keep the set deliberately small:

```text
croquis
figure_drawing
tonal_study
line_study
free_draw
```

A mode may be renamed/removed during implementation if it duplicates another guide and
adds no product distinction. Do not prebuild a large registry.

## ModeGuide contract

Each retained mode may declare only authoring guidance such as:

- primary observations;
- recommended construction/mark grammar;
- useful omissions/simplifications;
- finish emphasis;
- completion questions.

A ModeGuide must not own:

```text
stage count
phase cursor
advance()/close()
mode-specific history/session
mode-specific renderer/inspection implementation
automatic artistic PASS
```

## Capability expectations

### `croquis`

Gesture, balance, major mass, stance, overlap, line economy, selective contour.

### `figure_drawing`

Pose/form continuity, anatomy/garment relation, contact, hands/feet, identity-bearing
finish when requested.

### `tonal_study`

Large shadow family, light family, value grouping, form turn, edge hierarchy. Use
B07-R1 region-value primitives as authored decisions. It must not be line construction
plus a post-filter.

### `line_study`

Contour, shape/rhythm, overlap and directional emphasis with minimal value dependence.

### `free_draw`

Loose grammar driven by declared subject/composition/gesture/focal/shape-language intent.
Works with observed, imaginative, or hybrid authority from B13.

## Deliverables

- compact declarative ModeGuide records/references for retained modes;
- no separate session/history/render pipeline;
- mode lookup/resolution and portable serialization where required;
- deterministic fixtures proving every mode resolves to guidance and uses the same core;
- contract tests that reject lifecycle fields/methods if applicable;
- B14 capsule and status transition to B15.

## Definition of Closed

- [x] Every retained mode reuses the same `DrawingSession`, action history, inspection,
      residual/correction, checkpoint/replay, and renderer core.
- [x] Retained modes have distinct declared authoring value rather than aliases with new
      names.
- [x] Tonal mode uses authored value/edge/form guidance, not renderer-only styling.
- [x] Free-draw works with B13 authority semantics and does not require fake reference
      evidence.
- [x] No mode lifecycle state, automatic artistic verdict, or pipeline duplication exists.
- [x] Technical fixtures cover lookup/serialization/integration only; visual usefulness is
      explicitly deferred to D01–D05.
- [x] Capsule/docs/tests complete and B15 is next sole WIP.

## Non-goals

Fresh subject dogfood, cross-agent reproducibility, large style catalogs, and exhaustive
mode benchmarks.
