# B14 — Cross-agent reproducibility

State: **SKELETON**
Depends: B13

## Goal

Prove that the canonical skill route and evidence/correction loop transfer to fresh
workers without hidden project history or Pn anchoring.

## Deliverables

- at least two independent fresh-worker runs from the same sealed input contract;
- evaluator packet that hides prior rationale/verdict while exposing required images;
- divergence analysis for observation, residual priority, edit strategy, quality, cost,
  and failure modes;
- minimal instruction fixes justified by repeated divergence.

## Definition of Closed

- [ ] Workers receive only installed/package skill, subject, request, and declared intent.
- [ ] No answer image, authored coordinate table, prior trace, or legacy stage packet leaks.
- [ ] Both runs use the same canonical core and Pn-free reading route.
- [ ] Independent review finds comparable decision quality and acceptable final quality;
      identical strokes are not required.
- [ ] Cost/evidence differences are recorded without optimizing away necessary inspection.
- [ ] Any instruction change is rerun on the affected case and does not create a second
      workflow.
- [ ] Reproducible fixtures, evaluator notes, limitations, and capsule pass.

## Non-goals

Statistical claims about all models or modes, automatic artistic scoring, and parallel
production implementations.
