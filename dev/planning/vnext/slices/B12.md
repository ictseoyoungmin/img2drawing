# B12 — Legacy runtime and persistence isolation

State: **SKELETON**
Depends: B11

## Goal

Make R23 runtime/checkpoint compatibility an explicit adapter/namespace rather than a
dependency visible from the canonical vNext route.

## Deliverables

- dependency audit for root exports, `run.py`, `stages/`, `review/`, reference models,
  checkpoint/replay, examples, and package metadata;
- explicit legacy import/entry point and vNext-only import surface;
- old checkpoint read/migrate/refuse strategy with versioned errors;
- removal of vNext-to-legacy orchestration dependencies while preserving shared core
  capabilities;
- migration documentation and compatibility tests.

## Definition of Closed

- [ ] Importing/using the canonical vNext surface does not load or call stage registry,
      stage review, reopen, or Pn persistence machinery.
- [ ] One shared stroke/history/renderer core remains; no copied `core_v2` tree exists.
- [ ] Supported legacy checkpoints load only through the explicit compatibility path;
      unsupported forms fail with actionable version/migration errors.
- [ ] Subject/action/state/renderer provenance survives any supported migration.
- [ ] Root exports and package metadata make vNext canonical and legacy opt-in.
- [ ] R23 regression, vNext suite, dependency/orphan audit, migration fixtures, and
      capsule pass.

## Non-goals

Physical deletion of all R23 files/public symbols belongs to B18. Do not redesign the
closed vNext state model for directory aesthetics.
