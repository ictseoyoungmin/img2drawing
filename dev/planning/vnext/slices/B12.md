# B12 — Legacy runtime and persistence isolation

State: **ACTIVE**
Depends: B11

## Goal

Make R23 runtime/checkpoint compatibility an explicit opt-in adapter/namespace rather than
a dependency visible from the canonical vNext route. Preserve shared core capabilities;
do **not** physically delete R23 in this slice.

## Target boundary

Conceptually:

```text
img2drawing              → canonical vNext surface
img2drawing.legacy.r23   → explicit compatibility surface
```

Exact module names may differ, but the attention/dependency boundary must be real.

## Deliverables

- dependency audit for root exports, `run.py`, `stages/`, `review/`, reference models,
  checkpoint/replay, examples, and package metadata;
- explicit legacy import/entry path plus clean vNext-only import surface;
- old checkpoint read/migrate/refuse strategy with versioned actionable errors;
- removal of vNext-to-legacy orchestration dependencies while preserving shared
  stroke/history/renderer/tool capabilities;
- compatibility support matrix and migration documentation;
- import/orphan/dependency tests and B12 capsule.

## Definition of Closed

- [ ] Importing/using canonical vNext does not load or call stage registry, stage review,
      reopen, Pn progression, or R23 persistence orchestration.
- [ ] One shared stroke/history/renderer/tool core remains; no copied `core_v2` tree.
- [ ] Supported legacy checkpoints load only through explicit compatibility behavior;
      unsupported forms fail with version/migration guidance.
- [ ] Subject/action/state/renderer provenance survives supported migration.
- [ ] Root exports/package metadata make vNext canonical and legacy opt-in.
- [ ] Existing R23 regression remains available as compatibility evidence while B12 is
      being implemented.
- [ ] No physical deletion of legacy implementation occurs here.
- [ ] No fresh dogfood is required; dependency/import/migration fixtures close the
      technical boundary.
- [ ] Capsule/docs/tests complete and B13 is next sole WIP.

## Physical retirement policy

Physical R23 retirement is deliberately moved **after** B18 and D01–D06 dogfood. It is
post-validation **R03**, not B12 and not B18. This keeps rollback/compatibility evidence
available while the completed vNext product is still being exercised.

## Non-goals

Deleting historical Git evidence, erasing the frozen baseline, redesigning the closed
vNext state model for directory aesthetics, and fresh dogfood.
