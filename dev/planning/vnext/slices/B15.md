# B15 — Style authoring completion

State: **ACTIVE**
Depends: B14

## Goal

Complete a small, useful authoring-style surface without turning style into a renderer
post-filter, inheritance graph, or mode-specific pipeline.

## Style contract

```text
StyleGuide
  = how the Agent authors marks

RenderProfile
  = how authored marks are materialized/rasterized
```

They remain separate.

Style selection may influence:

- line confidence / taper / pressure character;
- construction visibility;
- contour/detail density;
- hair/fold/grouping strategy;
- value/edge policy;
- simplification and selective emphasis.

It may not silently alter subject geometry truth, replace the renderer, or auto-transform
existing strokes.

## Minimal preset surface

Start small and justify every retained preset:

```text
pencil_loose
graphite_academic
graphite_tonal
```

Use one-base + explicit overrides only. Do not introduce multi-level inheritance, plugin
registries, or a general style DSL.

## Custom style

Human-readable custom prose may be structured by the Agent into a `StyleGuide`-like
record. The runtime does not need to become a natural-language parser. Ambiguous or
conflicting prose should surface as an explicit clarification/escalation condition rather
than silently overriding geometry or task constraints.

## Mid-session style change

Changing style appends provenance but does not rewrite prior marks automatically. The
Agent decides what to:

```text
keep
retire
replace
add
```

Any actual visual change remains an explicit history edit and must replay/resume
normally.

## Deliverables

- evidence-backed minimal preset definitions;
- one-base + override resolution;
- portable custom structured style representation where needed;
- mid-session style-change provenance and explicit edit semantics;
- conflict/error rules for invalid overrides, unknown base, ambiguous prose, and task /
  subject constraints that outrank style preferences;
- deterministic comparison fixtures using the same geometry/session core;
- B15 capsule and status transition to B16.

## Definition of Closed

- [ ] Presets/overrides/custom structured guidance affect declared authoring policy, not
      renderer-only post-processing.
- [ ] Geometry/reference truth outranks style preferences.
- [ ] Mid-session style changes are append-only provenance and do not fork authoritative
      history.
- [ ] Actual changed marks remain explicit replayable edits.
- [ ] Invalid/unknown/conflicting style inputs have explicit behavior.
- [ ] Preset count stays small and justified; no inheritance graph, marketplace, or
      per-style session/renderer tree.
- [ ] Technical fixtures show distinct guidance/authoring parameters; full visual style
      quality is deferred to D04–D05 after B18.
- [ ] Capsule/docs/tests complete and B16 is next sole WIP.

## Non-goals

Unlimited media simulation, a general-purpose style DSL, broad preset catalog, automatic
style scoring, and fresh dogfood.
