# B18 — Dogfood-ready system freeze

State: **CLOSED**
Activated: **2026-09-02** as the sole production WIP after B17 closure.
Closed: **2026-09-02**
Depends: B17

## Goal

Close the implementation phase. After B18, the product surface is considered complete
enough for full fresh validation; new work should be defect-driven REOPEN of responsible
B-slices rather than continued feature accretion.

B18 is **not** physical R23 retirement. Retirement moves to post-dogfood R03.

## Freeze targets

Freeze the currently supported public contract for:

- canonical vNext `DrawingSession` surface;
- checkpoint/session schema and migration behavior;
- `DrawingIntent` axes and provenance;
- finish/completion record contract;
- `RenderProfile` and replay/GIF semantics;
- observed/imaginative/hybrid reference-authority rules;
- retained ModeGuide set;
- retained StyleGuide preset/override/custom structure;
- authoring/edit ergonomics surface;
- legacy compatibility boundary;
- package/public API/support matrix.

“Freeze” means no known implementation TODO is intentionally deferred into dogfood as a
new feature requirement. It does not prevent responsible-slice REOPEN when dogfood finds
a defect.

## Deliverables

- implementation-completeness inventory across B09–B17;
- open TODO/placeholder/dead-end audit;
- canonical API/schema/profile snapshot or version identifiers;
- cross-slice consistency audit for docs, package, checkpoints, output, intent, modes,
  style, legacy adapters, and editing surface;
- clean build/install/unit/integration/replay regression;
- dogfood input contract and evidence directory template that contain no answer images,
  prior rationale, authored coordinates, or Pn packets;
- B18 capsule declaring the system ready to enter D01–D06 validation.

## Definition of Closed

- [x] B09–B17 are CLOSED with no simultaneous production WIP.
- [x] No known product-surface implementation TODO is being hidden as “dogfood will decide
      the API later”.
- [x] Canonical public API/session schema/intent/RenderProfile/mode/style/edit surfaces are
      versioned or otherwise explicitly frozen for validation.
- [x] Package installs cleanly and canonical mechanical create/resume/inspect/correct/
      finish/replay/output regressions pass.
- [x] Legacy compatibility boundary is isolated but physically retained for rollback and
      validation.
- [x] D01–D06 sealed input/evaluator contracts are documented and do not leak historical
      solution data.
- [x] No fresh dogfood is performed as part of B18 closure itself.
- [x] B18 capsule and `VALIDATION_RELEASE.md` are current; next work is D01, not another
      B-slice feature.
