# B18 — Physical R23 retirement

State: **SKELETON**
Depends: B17

## Goal

Remove or archive the remaining Pn/R23 files and public surface after vNext release truth
and the compatibility decision are proven, leaving no ambiguous normal route.

## Deliverables

- final inventory: remove, archive externally, keep as shared capability, or keep as a
  time-bounded compatibility adapter;
- deletion/migration of stage runtime, review manifests, playbooks, stage references,
  stale exports/tests/examples, and obsolete package data as approved by the support
  policy;
- tombstone/migration notes for intentionally broken imports or checkpoints;
- dead-code, dependency, package-content, and fresh-install audits.

## Definition of Closed

- [ ] Canonical package/source/doc search finds no Pn orchestration outside explicitly
      approved historical or compatibility records.
- [ ] No vNext import, example, test fixture, or release path depends on retired modules.
- [ ] Shared stroke/history/renderer capabilities remain single-source and tested.
- [ ] Supported checkpoint migration works; unsupported legacy inputs fail with the
      documented actionable error.
- [ ] Removed paths have no live callers, broken links, duplicate replacements, or package
      entries.
- [ ] Full tests, clean build/install/E2E, provenance/replay checks, and direct output
      review pass.
- [ ] Final capsule records exactly what was removed, retained, and recoverable from the
      frozen Git baseline.

## Non-goals

Deleting historical Git evidence or the frozen B00 baseline. Retirement is about the
shipped/current path, not erasing project history.
