# B13 — Same-subject end-to-end closure

State: **SKELETON**
Depends: B12

## Goal

Take one difficult observed subject from fresh input through intent, construction,
residual corrections, finish, replay, and export at flagship quality using only the
canonical vNext route.

## Deliverables

- clean run directory with complete portable provenance;
- initial construct, prioritized residual sequence, before/after inspections, final
  output, replay/GIF, and concise decision log;
- representative evidence subset suitable for the repository;
- independent whole-image visual review and failure notes.

## Definition of Closed

- [ ] Run starts from skill + subject + request without ideal-stroke image, hidden
      landmarks, legacy target, or historical action IDs.
- [ ] No Pn guidance/runtime is used by the worker.
- [ ] Macro pose, mass, balance, overlap, limbs/feet, and prop relation are directly
      reviewed before finish detail.
- [ ] Each accepted major correction has fresh before/after evidence.
- [ ] Finish matches declared intent and contains no material residual identified by the
      final whole review.
- [ ] Checkpoint/resume and final PNG/replay/GIF parity pass.
- [ ] Temporary artifacts are not all committed; the representative subset is sufficient
      and reproducible.
- [ ] Independent review, tests, evidence index, and capsule pass.

## Non-goals

Cross-agent claims or multi-mode generalization; those require B14/B15.
