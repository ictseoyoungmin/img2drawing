# B13 — Reference authority and subjectless runtime

State: **CLOSED**
Depends: B12

## Goal

Turn B08's scaffolded `imaginative` / `hybrid` / `free_draw` declarations into real
runtime capability without creating fake reference authority or parallel session types.

## Reference authority contract

```text
observed
  readable subject is evidence authority

imaginative
  no external subject is required
  declared intent/composition/shape goals are the comparison authority

hybrid
  preserved reference constraints and deliberate transformations are recorded separately
```

All three reuse one `DrawingSession`, history, inspection/correction core, checkpoint,
replay, and output path.

## Deliverables

- subjectless `DrawingSession` creation with explicit canvas specification;
- observed-session behavior preserved unchanged;
- inspection/correction behavior that works when no subject image exists;
- hybrid provenance for preserved vs transformed constraints;
- reference-dependent measurement/overlay APIs that fail clearly or become unavailable
  when no reference exists rather than fabricating authority;
- persistence/resume integrity for observed, imaginative, and hybrid sessions;
- deterministic fixtures for all authority modes;
- B13 capsule and status transition to B14.

## Example target surface

The exact API can change, but a subjectless path should be possible conceptually:

```python
DrawingSession.create(
    canvas=(1024, 1024),
    intent=imaginative_intent,
)
```

Observed work continues to use a readable subject. Hybrid may carry a subject plus
explicit preserved/transformed constraints.

## Residual semantics

- observed residual: subject ↔ drawing mismatch;
- imaginative residual: declared intent ↔ drawing mismatch;
- hybrid residual: preserved reference constraint or declared transformation ↔ drawing
  mismatch.

The record type should remain shared; do not create separate residual systems.

## Definition of Closed

- [x] Subjectless session creation/checkpoint/resume works through canonical
      `DrawingSession`.
- [x] Observed subject-backed behavior and hashes remain compatible.
- [x] Subjectless inspection does not require or invent a subject overlay.
- [x] Reference-only measurement APIs fail explicitly when reference evidence is absent.
- [x] Hybrid sessions distinguish preserved and transformed constraints in provenance.
- [x] One correction core serves all reference modes.
- [x] No `ObservedSession`, `ImaginativeSession`, or `HybridSession` parallel pipelines.
- [x] Technical fixtures cover persistence/orphan/stale behavior; full drawing quality is
      deferred to D04–D05 after B18.
- [x] Capsule/docs/tests complete and B14 is next sole WIP.

## Non-goals

Mode-quality validation, broad style testing, cross-agent proof, automatic intent
satisfaction scoring, and fresh dogfood.
