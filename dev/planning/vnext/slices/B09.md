# B09 — Finish / recognition authoring

State: **CLOSED**
Depends: B08 + closed B01-R1/B07-R1 constraints

## Goal

Make `finish_intent` alter actual authoring decisions through the same stage-free
`DrawingSession`, without creating P7, `FinishStage`, likeness scoring, or a mode-specific
pipeline. Finish must preserve macro pose/form/composition and obey **form before value**.

## Product contract

Supported finish intents:

```text
pose
subject
form_light
expressive
```

They are authoring targets, not lifecycle states.

### Pose finish

Prioritize gesture, balance, stance, silhouette, major masses, limb chains, major prop
relation, and line economy. Dense identity/detail is optional unless required by the task.

### Subject finish

Recognition is relational rather than "detail exists" bookkeeping.

- face: eye spacing/direction, eyelid/iris relation, nose-mouth-chin relation,
  cheek/jaw/hair occlusion;
- hair: outer envelope, major groups, termination direction, overlap with face/neck/body;
- hands/feet: parent-chain relation, contact, visible vs occluded termination, major mass;
- clothing: garment mass, openings, compression/tension cues, overlap, distinctive seams;
- prop: topology, width changes, body contact, overlap, terminal mass, distinctive parts.

A hand is not complete because fingers exist; a face is not complete because eyes/nose/
mouth exist; hair is not complete because repeated strands exist.

### Form-light finish

Use large light/shadow families, value grouping, edge hierarchy, and form turn. Tone may
reinforce an already-correct form but may not manufacture missing limb thickness,
torso/limb separation, garment volume, or contact.

### Expressive finish

Prioritize composition, focal hierarchy, shape rhythm, selective simplification, and
style consistency against declared intent while preserving explicitly required geometry
or reference constraints.

## Observation constraints inherited from B01-R1

Before a finish mark or correction:

1. name what the line separates;
2. confirm the measurement method can actually see that boundary;
3. confirm the ending/detail was observed rather than assumed.

Repeated marks inherit structural variation instead of becoming ruler-like sawteeth or
uniform texture rows. Refine the parent chain before its terminal detail.

## Deliverables

- compact finish guidance/reference docs for pose/subject/form-light/expressive;
- relational recognition guidance for face/hair/hands/feet/clothing/props;
- APIs/data only where needed to carry finish authoring provenance; no finish lifecycle;
- deterministic/synthetic fixtures that demonstrate distinct authored mark/value choices
  without claiming unseen-subject quality;
- regression coverage for stale/orphan provenance if new records are introduced;
- B09 capsule and planning/status update.

## Definition of Closed

- [x] `pose`, `subject`, `form_light`, `expressive` remain plain intent values, not
      stage/cursor/gate state.
- [x] Finish guidance can select materially different mark/value/detail policies through
      the same `DrawingSession`/history core.
- [x] Recognition checks are relational and subject-specific when reference evidence
      exists.
- [x] Detail cannot justify unresolved macro pose/form/contact errors.
- [x] Tonal guidance requires line/tone-off structural readability first and groups
      observed value families rather than arbitrary dark bands.
- [x] Expressive guidance records preserved constraints instead of silently sacrificing
      required geometry.
- [x] No automatic likeness, style, or artistic PASS/FAIL is introduced.
- [x] Tests validate data/provenance/compatibility only; full visual robustness is
      explicitly deferred to D01–D03 after B18.
- [x] Capsule and docs are complete; B10 becomes the next sole WIP.

## Closure evidence policy

B09 does **not** start a fresh visual dogfood. Allowed closure evidence:

- deterministic/synthetic authoring fixtures;
- existing preserved subject/evidence from closed slices;
- unit/integration regression;
- direct review that the guidance/API does not create a hidden lifecycle.

Unseen-subject quality, mode generalization, and cross-agent proof belong to D01–D06.

## Non-goals

Universal completion verdicts, full drawing-mode matrix, subjectless runtime, new renderer
families, broad style catalogs, and fresh dogfood.
