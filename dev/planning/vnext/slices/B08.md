# B08 — DrawingIntent and mode/style scaffolding

State: **CLOSED**
Depends: B07

Activated: **2026-08-31**

### Activation contract

- `DrawingIntent` is portable plain data. The four axes are independently validated
  values; selecting or changing one never derives, advances, closes, or gates another.
- `DrawingSession` owns the current intent and append-only intent provenance. An intent
  event records data and a reason at the existing history cursor; it does not create a
  parallel drawing-history branch or rewrite geometry.
- `ModeGuide` and `StyleGuide` are immutable authoring guidance. They contain no
  required phase count, stage/cursor, `advance`, `close`, or visual verdict contract.
- `StyleGuide` describes how an agent authors marks (line, construction, detail, value,
  edge, and notes). It is not a raster filter, renderer selector, or inheritance graph.
- The only compatibility mapping in scope is an explicit lookup such as
  `full_body_croquis → observed/croquis`; it does not make the alias a lifecycle state.
- Serialization is versioned and backward-compatible for sessions without intent.

## Goal

Add the smallest plain-data intent layer needed to configure one shared core for
different reference, drawing, finish, and style goals without creating mode pipelines.

## Internal closure order

1. **B08.1 `DrawingIntent`:** independent `reference_mode`, `drawing_mode`,
   `finish_intent`, `style_profile` values and provenance.
2. **B08.2 `ModeGuide`:** primary observations, recommended grammar, omissions,
   finish emphasis, completion questions.
3. **B08.3 `StyleGuide`:** start with only `pencil_loose` and
   `graphite_academic`; authoring policy, not raster filter.
4. **B08.4 overrides:** one base + explicit overrides; custom prose structuring remains
   Agent responsibility.

Only one internal item may be production-active at once.

## Deliverables

- portable, versioned plain-data models and lookup/resolution rules;
- session provenance for selected/changed intent without a parallel history branch;
- two minimal mode/style fixtures that exercise the existing core;
- documented compatibility mapping such as `full_body_croquis → observed/croquis`.

## Closure record — orthogonal intent scaffold

Closed: **2026-08-31**

`DrawingIntent`, `IntentProvenance`, and `IntentChangeRecord` are portable versioned
records. `DrawingSession.create(intent=...)` and `set_intent(..., reason=...)` persist
the current snapshot and an append-only digest chain at the existing action cursor;
changing intent leaves strokes, action history, and renderer selection untouched.
Sessions created before B08 resume with no intent fields.

`ModeGuide` exposes only observations, recommended grammar, omissions, finish emphasis,
and questions. `StyleGuide` exposes direct line/construction/detail/value/edge guidance
for `pencil_loose` and `graphite_academic`; explicit one-base field overrides are
supported. Neither guide has lifecycle fields or a pixel post-filter path. The explicit
`full_body_croquis` compatibility lookup returns an ordinary observed/croquis intent.
