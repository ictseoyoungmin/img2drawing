# B08 — DrawingIntent and mode/style scaffolding

State: **SKELETON**
Depends: B07

## Goal

Add the smallest plain-data intent layer needed to configure one shared core for
different reference, drawing, finish, and style goals without creating mode pipelines.

## Internal closure order

1. **B08.1 `DrawingIntent`:** independent `reference_mode`, `drawing_mode`,
   `finish_intent`, `style_profile` values and provenance.
2. **B08.2 `ModeGuide`:** primary observations, recommended grammar, omissions,
   finish emphasis, completion questions.
3. **B08.3 `StyleGuide`:** start with only `pencil_loose` and
   `graphite_academic`; authoring policy, not raster filter.
4. **B08.4 overrides:** one base + explicit overrides; custom prose structuring remains
   Agent responsibility.

Only one internal item may be production-active at once.

## Deliverables

- portable, versioned plain-data models and lookup/resolution rules;
- session provenance for selected/changed intent without a parallel history branch;
- two minimal mode/style fixtures that exercise the existing core;
- documented compatibility mapping such as `full_body_croquis → observed/croquis`.

## Definition of Closed

- [ ] Orthogonal fields can be combined without implicit coupling or phase transitions.
- [ ] `DrawingSession` remains the sole session/history authority.
- [ ] Guides contain no required phase count, cursor, advance, close, or visual verdict.
- [ ] Style selection affects declared authoring guidance; no post-filter-only claim.
- [ ] Mid-session changes are provenance events and do not silently rewrite geometry.
- [ ] Unknown/invalid values and portable serialization/resume are tested.
- [ ] No mode-specific session, renderer duplicate, inheritance graph, or plugin registry.
- [ ] Integration test, documentation, duplicate audit, and capsule pass.

## Non-goals

Full tonal/free-draw behavior, new renderer families, intent-aware completion, and broad
preset catalogs remain later slices.
