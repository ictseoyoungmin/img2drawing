# B17 — Package, public API, and release-candidate truth

State: **CLOSED**
Closed: **2026-09-02**
Depends: B16

## Goal

Make source tree, built package, installed behavior, public API, docs, examples, migration
surface, and CI tell the same **release-candidate** truth before full visual dogfood begins.
B17 proves packaging/integration readiness; it does not claim final product quality.

## Deliverables

- lean package inventory and exclusion policy for workbench/dogfood/raw evidence/temp data;
- public API/support matrix for canonical vNext and explicit legacy compatibility;
- canonical examples for representative observed and subjectless intent mechanics;
- version/release-candidate notes and migration guidance;
- clean-install smoke tests covering create/resume/inspect/correct/finish/replay/output;
- docs link/path checks, package-content audit, version/API parity checks, CI wiring;
- license/security/basic supply-chain audit for shipped dependencies/data;
- B17 capsule and status transition to B18.

## Canonical package truth

Normal documentation and imports must lead to vNext `DrawingSession` and stage-free
references. R23/Pn may appear only in explicit compatibility/history/migration context.

A built artifact must not silently include:

- raw dogfood runs;
- temporary plans/caches;
- local absolute paths;
- answer/reference targets not required at runtime;
- stale stage-review docs presented as normal workflow;
- development-only calibration/evidence unless runtime genuinely requires the data.

## Definition of Closed

- [x] Wheel/sdist contains only required runtime modules/data, canonical references,
      justified presets/profiles, license, migration/support docs, and chosen examples.
- [x] Clean environment can install/import and run representative **mechanical** vNext
      workflows including checkpoint/resume and canonical output.
- [x] Source, built artifact, and installed API/version metadata agree.
- [x] No README/example/package description/CI command presents R23/Pn as normal route.
- [x] Legacy support matches B12's explicit compatibility matrix.
- [x] Subjectless/reference-authority capability from B13 is represented honestly in API
      docs/examples without fake quality claims.
- [x] Package/content/link/security/license audits pass.
- [x] B17 does not claim unseen-subject or cross-agent visual quality; that starts after
      B18.
- [x] Capsule/docs/tests complete and B18 is next sole WIP.

## Non-goals

Physical R23 deletion, final dogfood quality certification, broad performance tuning
without measured need, and fresh visual dogfood.
