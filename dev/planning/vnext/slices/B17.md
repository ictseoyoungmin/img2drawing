# B17 — Release truth

State: **SKELETON**
Depends: B16

## Goal

Make the shipped package, docs, examples, CI, and fresh-install behavior tell the same
truth as the canonical vNext implementation.

## Deliverables

- lean package inventory and exclusion policy for dogfood/workbench/evidence;
- version/release notes and migration guide;
- canonical examples for representative observed and non-croquis intent;
- clean-install smoke/E2E checks, docs link checks, package-content audit, and CI wiring;
- public API and compatibility support matrix.

## Definition of Closed

- [ ] Built wheel/sdist contains only required runtime data, references, presets, license,
      and canonical examples/docs.
- [ ] No stale package description, README, example, or CI command presents R23/Pn as the
      normal route.
- [ ] Fresh environment can install, import, run a representative vNext job, resume it,
      inspect it, and export canonical output/replay.
- [ ] Legacy compatibility is explicit and matches the B12 support matrix.
- [ ] Source tree, built artifact, and installed behavior pass version/API parity checks.
- [ ] Temporary plans, caches, raw dogfood runs, and hidden local paths are excluded.
- [ ] Release audit, security/license check, direct output review, and capsule pass.

## Non-goals

Physical legacy deletion before the release truth is proven; B18 owns final retirement.
