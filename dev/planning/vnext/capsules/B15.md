## Purpose

B15 completes style as portable Agent authoring policy while preserving the B11 output
boundary:

```text
StyleGuide    = how the Agent authors explicit marks
RenderProfile = how the runtime materializes those authored marks
```

Selecting or changing style never rewrites geometry, history, existing pixels, or the
renderer. Visual change remains an explicit draw/retire/replace/fill action.

## Retained surface

The single canonical registry contains exactly three distinct presets:

- `pencil_loose`: economical searching lines, pressure/speed variation, sparse value;
- `graphite_academic`: measured strokes, connected form, grouped value, selective edges;
- `graphite_tonal`: compact calibrated value regions, preserved lights, form-directed
  boundaries, and hard/soft/lost edge hierarchy.

`resolve_style_guide(base, overrides)` replaces named fields on exactly one base. Unknown
fields, another base, inheritance, and plugin/marketplace composition are rejected. The
resolved full guide remains portable through the existing StyleGuide schema.

## Structured custom and precedence contract

`StyleGuide.custom("custom:<identifier>", ...)` requires every structured authoring field;
the runtime does not parse natural-language prose. A custom identifier without a complete
guide, mismatched identifier, or attempt to combine custom guidance with base overrides
fails explicitly. Portable custom dictionaries round-trip through `StyleGuide.from_dict`.

The Agent supplies any unresolved terms or known higher-priority conflicts during
resolution. Unresolved prose raises `StyleClarificationRequired`; task/reference/geometry
conflicts raise `StyleConflictError`. This enforces the declared precedence without
pretending the runtime can infer semantic conflicts:

```text
task/reference/geometry truth > finish policy > style preference
```

## Mid-session changes and shared core

`DrawingSession.set_intent()` records a style-profile change in the existing append-only
intent provenance at the current action cursor. It changes neither drawing-state hash nor
cursor nor `RenderProfile`. The Agent then explicitly keeps, retires, replaces, or adds
marks through the ordinary history-safe API; checkpoint, replay, resume, inspection, and
correction continue on the same authoritative history.

The deterministic fixture authors identical geometry under all three presets. State hash,
canonical PNG, and RenderProfile remain identical because presets do not auto-transform
marks. A separate mid-session case proves selection-only invariance, then one explicit
replacement advances history and survives resume. One custom guide also round-trips.
