## Purpose

B13 turns observed, imaginative, and hybrid declarations into runtime truth through one
canonical `DrawingSession`:

```text
observed    → readable subject hash
imaginative → explicit canvas + declared goals
hybrid      → subject hash + preserved/transformed constraints
```

`ReferenceAuthority` is immutable per session and has its own portable schema/digest.
It does not score the drawing, choose residuals, or create a mode pipeline.

## Public surface

```python
authority = ReferenceAuthority.imaginative(("dominant ascending arc", "small counter-shape"))
session = DrawingSession.create(
    canvas=(1024, 1024),
    output_dir="out",
    intent=DrawingIntent(reference_mode="imaginative", drawing_mode="free_draw"),
    reference_authority=authority,
)
```

Observed creation remains source-compatible and derives an observed authority. Hybrid
creation requires a subject plus at least one preserved and one transformed
`ReferenceConstraint`; transformed constraints require explicit transformation and
rationale.

`set_intent()` may change mode, finish, or style axes but cannot change the session's
reference mode after evidence already depends on it.

## Drawing-only inspection

The existing `InspectionSheet` handles both subject-backed and subjectless evidence.
Subjectless quick inspection creates only `inspection_sheet.png`, `raw_drawing.png`, and
`inspection.json`. It creates no placeholder subject, registration, registered drawing,
contrast overlay, or measurements artifact. Registration, overlay controls,
subject-space ROI/guide/grid/measurement inputs, and `require_reference()` fail through
`ReferenceUnavailableError`.

Artifact telemetry counts the actual manifest rather than a hard-coded observed artifact
set. Each inspection binds the immutable authority digest as well as state, cursor, and
intent provenance.

## Persistence and shared core

- Checkpoints store `subject: null` for imaginative work and the complete authority plus
  digest for every mode.
- Pre-B13 observed checkpoints derive observed authority without action/state hash drift.
- A pre-B13 hybrid scaffold requires an explicit authority override; preserved and
  transformed constraints are never inferred.
- Tampered authority digests, subject/authority mismatch, intent/authority mismatch, and
  unavailable reference operations are rejected.
- Subjectless sessions use the same observation, draw/edit, inspection history,
  residual/correction, finish, render, replay/GIF, checkpoint, and resume implementations.
- No `ObservedSession`, `ImaginativeSession`, `HybridSession`, subjectless package, or
  parallel correction/output tree exists.
