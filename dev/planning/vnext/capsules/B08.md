# B08 Context Capsule — orthogonal drawing intent

## Purpose

B08 adds a small, portable intent layer without turning names into a lifecycle cursor:

```text
DrawingIntent (four independent values)
  → one DrawingSession/history
  → ModeGuide / StyleGuide authoring guidance
  → observe → draw → inspect → correct → finish
```

`reference_mode`, `drawing_mode`, `finish_intent`, and `style_profile` are selections.
They do not advance, close, reopen, gate, fork history, select a renderer, or rewrite
geometry.

## Public surface

```python
from img2drawing import (
    DrawingIntent, DrawingSession, compatibility_intent,
    resolve_mode_guide, resolve_style_guide,
)

intent = DrawingIntent(
    reference_mode="observed",
    drawing_mode="croquis",
    finish_intent="pose",
    style_profile="pencil_loose",
)
session = DrawingSession.create(subject="subject.png", output_dir="out", intent=intent)
event = session.set_intent(
    DrawingIntent(drawing_mode="figure_drawing", style_profile="graphite_academic"),
    reason="landmarks need more emphasis",
)
guide = resolve_mode_guide("figure_drawing")
style = resolve_style_guide("graphite_academic", {"edge_policy": ["sharpen one focal edge"]})
legacy_alias = compatibility_intent("full_body_croquis")
```

`DrawingIntent` validates independent axes and optional immutable `IntentProvenance`.
`IntentChangeRecord` stores the full intent snapshot, previous digest, reason, and the
existing action cursor. `intent` and `intent_history` are defensive/immutable session
views. `pencil_loose` and `graphite_academic` are the only built-in style bases;
`custom:<identifier>` is data that the Agent structures as prose and is not auto-parsed.

`ModeGuide` contains primary observations, recommended grammar, omissions, finish
emphasis, and completion questions. `StyleGuide` contains direct line, construction,
detail, value, edge, and authoring notes. Both are frozen data records. One-base explicit
field overrides are supported; inheritance and plugin registries are not.

## Persistence and safety

The existing `img2drawing.vnext.session.v2` checkpoint remains backward-compatible.
New sessions add optional `intent` and `intent_history` fields. Resume validates event
IDs, full intent payload digests, previous-digest chaining, current-intent binding, and
history-cursor bounds. Atomic `set_intent` rollback leaves the previous intent and event
list intact when checkpoint storage fails. Intent changes never enter the action log.
