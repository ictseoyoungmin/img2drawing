## Frozen contract

`dev/release/vnext/CONTRACT_FREEZE.json` is the D01-D06 baseline for package version
`0.6.0rc1` and `DrawingSession/0.6.0-vnext`. It pins canonical root exports, public
session members, persisted schema IDs, reference/mode/finish/style axes, RenderProfile,
state ownership, and the explicit R23 v1-v3 checkpoint boundary. Public or persisted
changes require a responsible-slice reopen and version/schema update; private helpers are
not over-frozen.

The freeze is a repository control-plane record, not Agent drawing guidance. It is kept
outside `skills/img2drawing/` so copying or packaging the skill does not expose release
snapshots, internal slice history, or a large API-member inventory to a fresh worker.

The canonical owner remains `img2drawing.vnext.session.DrawingSession` over one
`CanvasHistory`, `InspectionSheet`, renderer, and output path. The non-root-exported
`core.session.DrawingSession` is classified as a preserved low-level legacy replay
record. The function-form fill replacement is verified as a delegate to the session
method, and `VNextDrawingSession` is an identity alias. No second production core was
introduced.

## Sealed validation contract

`dev/dogfood/vnext-template/` contains text/JSON templates only. The Draft 7 schemas bind
D01-D06 case IDs, intent axes, reference authority, subject basename/hash, independent
evaluation artifacts, and reopen routing. Negative controls reject answer fields, path
traversal, a fake subject in imaginative work, and a prefilled evaluator verdict.
`seal_vnext_dogfood_input.py` additionally checks the real sibling subject digest, rejects
undeclared input-directory files, rejects legacy/prior-solution hints, and reports a
canonical JSON digest for the dispatch record.

The worker never receives an answer/target image, authored coordinates or landmarks,
prior session/actions/residuals, evaluator rationale/verdict, Pn packet, solution script,
or release-control snapshots. The evaluator brief is opened only after the run. B18 did
not prepare a real D01 subject, dispatch a worker, render new dogfood, or make an
artistic-quality claim.
