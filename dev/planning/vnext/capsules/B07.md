## Purpose

B07 keeps the B06 residual loop visually trustworthy while constraining review cost:

```text
quick whole sheet → Agent chooses residual → explicit edit → focused relation sheet (only if needed)
```

Evidence selection is Agent-authored and current-state-centric. It is not a lifecycle,
quality score, automatic ROI selector, or second inspection implementation.

The slice was narrowly reopened once on 2026-08-31 after review identified two gaps:
runtime mode misuse and resume read-event cross-binding. R1/R2 were reclosed without
changing the committed drawing sheets or correction geometry.

## Public surface

```python
from img2drawing import DrawingSession, EvidencePolicy, EvidenceReadRecord, EvidenceTelemetry

sheet = session.inspect(mode="quick")
event = session.record_evidence_read("000001", artifact="sheet")
print(session.evidence_telemetry.image_reads, event.stale)
```

`EvidencePolicy` records `mode`, optional escalation reason, and counts for ROIs, guides,
grid, and measurements. `quick` is the default whole-sheet presentation/read budget and
rejects all extras. `focused` accepts one to three explicitly supplied ROIs and no
guide/grid/measurement extras. `deep` accepts up to three ROIs plus guide/grid/measurement
evidence and always requires a human-readable escalation reason. Existing
`InspectionSheet` rendering and measurement helpers remain the single implementation;
the policy limits presentation/read scope, not the six-file renderer output.

`EvidenceReadRecord` validates and records a real artifact read. It binds the inspection
state digest to the current drawing digest and sets `stale=True` when the immutable sheet
is from an earlier state. Missing, invalid, or escaped artifacts raise an explicit
`evidence unreadable` error. `EvidenceTelemetry` is immutable, JSON-portable, and counts
inspection calls/review turns, generated and visual artifacts, image reads, and elapsed
work; it has no artistic decision field.

## Persistence and safety

The existing `img2drawing.vnext.session.v2` checkpoint schema remains compatible. New
sessions persist optional `evidence_telemetry`; old checkpoints resume with zero counters.
Inspection manifests carry the policy used to render that sheet, while inspection history
retains its B06 digest contract. Telemetry updates and read events use the existing atomic
checkpoint path and roll back in-memory state when the write fails.

No `current_stage`, `advance`, `close`, `reopen`, duplicate history, renderer, manifest
builder, automatic score, or mode-specific session was introduced. Resume additionally
rejects read events whose inspection ID, historical drawing hash, or manifest artifact
does not match the persisted inspection record.
