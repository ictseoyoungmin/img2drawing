# B11 Context Capsule — canonical render profile, replay, and GIF parity

Status: **CLOSED**
Closed: **2026-09-01**
Depends: B10
Next: B12 legacy runtime and persistence isolation

## Purpose

B11 binds canonical final PNG, cursor replay, and GIF export to one persisted
`RenderProfile`, one actual pencil-contact renderer, and one authoritative
`CanvasHistory`:

```text
CanvasHistory.state_at(cursor) + RenderProfile
  → pillow_pencil_contact.render
  → PNG frame / independent final PNG / encoded GIF
```

`StyleGuide` remains authoring advice and is absent from `RenderProfile`. Output code
copies the render-only IR view to apply profile-owned paper state and verifies that the
authoritative history did not mutate.

## Public surface

```python
profile = RenderProfile.canonical(width, height)
session = DrawingSession.create(..., render_profile=profile)
frame = session.render_at(cursor, "frame.png")
final = session.render_final("final.png")
replay = session.export_timelapse("replay", mode="every_n", every_n=4)
```

The session owns the profile; output calls cannot pass ad hoc renderer kwargs. The actual
`pillow_pencil_contact.RENDERER_ID` and `RENDERER_VERSION` are the single source for both
legacy core-session headers and vNext profiles/checkpoint headers.

## Durable replay contract

- Cursor N is the state after the first N authored actions.
- Cursor 0 and latest are always included. `action` emits all cursors; `every_n` samples
  while retaining endpoints.
- One `region.fill`/`region.replace` action produces one authored frame. Generated
  material contacts do not appear as fake history actions or frames.
- Ordinary/edit/region/final timing is explicit in the replay manifest.
- Pixel-work is calculated before output and rejected above the caller budget; encoded
  GIF bytes are also enforced against an explicit size limit.
- Latest replay PNG and an independently rendered canonical final PNG must match exactly
  by decoded pixel hash.
- GIF palette encoding uses a documented tolerance (maximum channel error 24, mean 2.0);
  measured values and the result are persisted.
- Profile/header/canvas/material/seed/compositing/encoding drift is rejected.

## Compatibility and consolidation

Pre-B11 vNext checkpoints with the exact old renderer header may resume without a
profile, but canonical output is unavailable until explicit `migrate_render_profile()`.
Unknown legacy headers are rejected. Legacy and vNext timelapse share cursor selection,
pixel hashing, GIF encoding, and the same actual renderer rather than duplicating those
mechanics. Internal free functions are not root exports; `DrawingSession` is the canonical
vNext entry point.

## Evidence and checks

- Deterministic fixture: `dev/fixtures/vnext-b11/run.py`.
- Focused rendering/timelapse/session regression: 25 passed.
- Full development regression: 168 passed, 5 pre-existing JSON-schema deprecation
  warnings.
- Fixture contains cursors 0, 1, 2, 3; exactly one region action/frame; exact independent
  final PNG parity; GIF within declared tolerance; and unchanged history/state.
- Direct review confirmed one renderer implementation and no StyleGuide/post-filter
  coupling.

This proves deterministic mechanics on synthetic input only. Visual usefulness across
real subjects and modes remains deferred until D01-D05.

## Reopen conditions

Reopen B11 if PNG/replay/GIF use different profiles or histories, latest PNG parity fails,
GIF exceeds declared tolerance, region actions expand into fake authored frames, renderer
metadata drifts silently, or output mutates geometry.
