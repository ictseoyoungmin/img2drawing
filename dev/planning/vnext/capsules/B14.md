## Purpose

B14 completes the smallest useful drawing-mode surface as immutable authoring guidance:

```text
croquis         → gesture, balance, stance, overlap, line economy
figure_drawing  → connected form, anatomy/garment relation, contact, hands/feet, identity
tonal_study     → authored value families, form turn, and edge hierarchy
line_study      → contour ownership, shape rhythm, overlap, directional emphasis
free_draw       → declared composition, gesture, focal hierarchy, and shape language
```

The modes are data selections, not workflows. No mode owns a stage, cursor, session,
history, renderer, inspection implementation, or artistic verdict.

## Public and persistence surface

`DRAWING_MODES` contains exactly the five retained values. `resolve_mode_guide()` returns
one immutable `ModeGuide`; its existing v1 portable schema round-trips every guide.
`DrawingSession.mode_guide` derives the current guide from `DrawingIntent` and persists
no duplicate mode state. Changing drawing mode appends normal intent provenance, changes
neither geometry nor action cursor, and resumes through the same checkpoint path.

## Distinct authoring value

- Croquis keeps the whole pose, support, mass relation, and economical selective contour
  primary.
- Figure drawing follows complete body chains, garment/body relation, contact, visible
  terminals, and requested identity-bearing relations.
- Tonal study explicitly requires form before value and `fill_region` for authored large
  value families; renderer filters and authored microhatching expansion are omissions.
- Line study asks what every line separates or connects and minimizes broad value.
- Free-draw requires concrete composition, gesture, focal, and shape-language goals. It
  works under observed, imaginative, and hybrid B13 authority without fake evidence.

## Shared-core evidence

The deterministic fixture runs five observed mode cases plus imaginative and hybrid
free-draw through one `DrawingSession` and `CanvasHistory` type. Every case draws,
inspects, renders canonical PNG, checkpoints, resumes with an identical state and guide,
and uses the same output implementation. The tonal case records one canonical
`region.fill` action; imaginative inspection emits only sheet/raw/manifest.
