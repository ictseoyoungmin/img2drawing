## Responsibility completed

B04 delivered the minimal executable vNext session boundary while preserving the
shared R23 drawing capabilities. It did not implement B05 construction grammar,
B06 correction policy, or any later slice.

## Public surface

Use `img2drawing.vnext.DrawingSession` (also available as the lazy root alias
`img2drawing.DrawingSession`):

```text
create → observe → draw/draw_many → inspect → explicit edits → repeat → finish
```

The facade provides `create`, `resume`, `observe`, `draw`, `draw_many`,
`replace_stroke`, `replace_segment`, `soft_lift`, `delete_stroke`, `inspect`,
`checkpoint`, and `finish`. No operation accepts or branches on a workflow stage.

## Authoritative inputs and ownership

- `AgentDrawingSession` and its `CanvasHistory` are the single authoritative
  action/state substrate.
- `StrokeIR` is a read-only current-state projection.
- The facade owns session metadata, subject identity, observation snapshots,
  inspection references, finish metadata, and checkpoint persistence.
- The B02+B03 `InspectionSheet` remains the sole inspection implementation.
- The shared `pillow_pencil_contact.render` remains the sole material renderer.

The internal compatibility stage `__vnext_compat__` is opaque provenance only.
Public snapshots clear the legacy stroke stage before hashing/rendering, so the
vNext state and renderer seed are independent of legacy stage labels. Authored
`tool_state` and nested metadata are not stripped.

## Frozen invariants

1. Stage-free API: no public stage argument, stage registry, stage manifest, stage
   transition, reopen bookkeeping, or visual verdict.
2. Single history authority: mutations append through shared `DrawingAction` and
   `CanvasHistory`; public state is a defensive projection.
3. Atomic mutation boundary: each accepted observe/edit/finish operation writes a
   checkpoint while holding the session lock. A failed checkpoint restores the
   prior in-memory state; `draw_many` commits as one batch.
4. Atomic inspection binding: `inspect()` locks one snapshot, renders it to
   `raw_drawing.png`, and supplies that same snapshot as `drawing_ir` to
   `InspectionSheet.create`. The sheet computes the stage-free digest and artifact
   SHA from that operation; callers cannot pair arbitrary raster/hash inputs.
5. Subject provenance: checkpoint and inspection reject subject bytes changed after
   session creation/resume.
6. Portable persistence: checkpoint JSON records subject basename, SHA-256, action
   history, current digest, renderer identity/version/seed domain, inspection
   history, and output-relative artifact references; it does not serialize absolute
   machine paths or R23 review/stage state.
7. Legacy compatibility isolation: importing `img2drawing.vnext` does not load
   `img2drawing.run` or `img2drawing.stages`; the root retains lazy legacy exports.

## Known limitations

- This slice validates state/orchestration integrity, not drawing likeness or
  visual completion.
- `finish()` stores metadata and preserves the checkpoint boundary; finish-quality
  semantics remain for a later slice.
- R23 replay remains legacy/reference-only. Its artifacts are not vNext PASS
  evidence.

## B05 handoff

B05 may add agent-authored observation/construction grammar on top of this facade.
It must keep the one-history authority, avoid stage branches, pass explicit
stage-free drawing actions, and call the existing `inspect()` path rather than
creating another renderer or inspection implementation. B05 is not activated by
this closure.

## Reopen conditions

Reopen B04 if a later change introduces stage semantics into the public facade,
breaks checkpoint atomicity or subject binding, loses inspection/correction
continuity on resume, or permits a second co-equal runtime/inspection path.
