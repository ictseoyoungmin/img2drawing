# B12 Context Capsule — legacy runtime and persistence isolation

Status: **CLOSED**
Closed: **2026-09-01**
Depends: B11
Next: B13 reference authority and subjectless runtime

## Purpose

B12 makes `img2drawing` the canonical stage-free package surface and places historical
R23 behavior behind one explicit, versioned, lazy boundary:

```text
img2drawing              → DrawingSession and shared capabilities
img2drawing.legacy.r23   → explicit R23 compatibility
```

Canonical import, `img2drawing.vnext`, and root wildcard import load no `run`, `stages`,
or `review` module. The compatibility module itself is lazy until a historical symbol or
operation is requested.

## Public and compatibility surface

The root `__all__` contains only canonical/shared names. Existing direct root accesses to
historical names remain non-advertised `DeprecationWarning` shims. One
`legacy.r23.LEGACY_EXPORTS` table is the sole historical-name authority.

```python
from img2drawing import DrawingSession
from img2drawing.legacy.r23 import (
    DrawingRun,
    inspect_checkpoint,
    migrate_checkpoint,
    resume_checkpoint,
)
```

Package `PUBLIC_API` now identifies `DrawingSession`; `DrawingRun` keeps separate R23
provenance constants inside the legacy runtime.

## Persistence contract

- R23 run checkpoint schemas v1, v2, and v3 support explicit resume and one-way migration.
- Unknown schemas fail with the supported version list and export-first guidance.
- A vNext checkpoint passed to the R23 adapter points to `DrawingSession.resume()`.
- Migration calls the existing `DrawingRun.resume()` validator and clones the existing
  `AgentDrawingSession`/`CanvasHistory`; there is no second parser or core.
- Subject identity, session lineage, exact action log/digest, source state digest, inert
  stage provenance, and target stage-free state digest are preserved.
- R23 checkpoints never persisted renderer identity. The migration record states that it
  is absent and binds the explicit canonical target `RenderProfile`; it does not guess.
- Stage progress, reviews, reopens, and legacy finish claims remain source history. They
  do not become canonical intent, evidence, or completion claims.
- Migration-generated observation tokens preserve action identity only and explicitly
  disclaim fresh vNext visual authority.

## Consolidation and guidance

No R23 file was deleted. No `core_v2`, alternate renderer, or parallel history exists.
Legacy tests and development tools now import the explicit namespace; only the dedicated
shim test exercises old root behavior. Skill and planning guidance is English-only. The
planning authorities were consolidated by role: README for navigation, ROADMAP for
sequence, CONTRACT for invariants, slice cards for execution, capsules for closed truth.

- Focused compatibility/session/R23 regression: 38 passed, including direct v1/v2/v3
  migration cases.
- Complete development regression: 177 passed with five pre-existing JSON-schema
  metaschema deprecation warnings.
- Deterministic fixture preserves session, cursor, exact action log, subject hash, source
  state provenance, target state, and explicit target render profile.
- Subprocess contract tests prove canonical and wildcard imports do not load legacy
  orchestration.
- Duplicate/orphan review found one shared `core/`, one renderer/tool implementation,
  one legacy export table, and no physical R23 deletion.

This closes mechanical compatibility and dependency isolation only. It makes no fresh
visual-quality or cross-agent claim.

## Reopen conditions

Reopen B12 if canonical imports load or advertise R23 orchestration, a supported legacy
checkpoint loses subject/action/state provenance, renderer absence is guessed rather than
recorded, unsupported schemas fail without guidance, a second core/parser appears, or
canonical docs return to root `DrawingRun` imports.
