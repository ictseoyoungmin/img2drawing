## Goal

Give an Agent one readable, current-state-bound inspection product with explicit
registration and read-only measurements. B02+B03 is one tightly coupled production
slice: the sheet, coordinate mapping, ROI display, guides, and measurements close
together.

## Frozen standalone contract

```python
sheet = InspectionSheet.create(
    subject="subject.png",
    drawing="current_drawing.png",
    drawing_state_hash="<stage-free digest from the session adapter>",
    registration=Registration(...),
    rois=[ROI("head", box=(...))],
    overlay="contrast",
    grid=Grid(...),
    guides=[PlumbLine(...), GroundGuide(...)],
    out_dir="inspection/",
)
```

- Subject coordinates are the inspection coordinate space. `Registration` explicitly
  maps subject points to canvas points; no auto-registration or resampling decision
  is inferred.
- The sheet contains whole subject, raw drawing, contrast overlay, and enlarged
  Agent-selected ROI panels in one image. Overlay is presentation-only and never
  replaces the raw drawing.
- `drawing_state_hash` is mandatory unless a `StrokeIR` is supplied for the
  stage-free digest adapter. It excludes workflow stage from drawing identity.
- Measurement functions return data/provenance only: grid, point, distance, angle,
  row/column profile, pixel sample, mapping, plumb, and ground guide. No function
  returns PASS/FAIL or mutates a stroke.
- Serialized artifact references are output-relative names. Input absolute paths are
  never written to the inspection manifest.

- [ ] 5px-scale alignment mismatch is visible in enlarged output
- [ ] drawing stroke remains visible over dark subject regions
- [ ] whole view and local ROIs are readable in one sheet
- [ ] sheet binds to the current drawing state hash
- [ ] subject ↔ canvas mapping is explicit and tested
- [ ] grid overlay is available in one call
- [ ] point distance and angle are available
- [ ] row/column profiles are available as data and JSON
- [ ] pixel sample includes provenance
- [ ] sheet and measurements do not create PASS/FAIL
- [ ] measurements never move geometry
- [ ] representative known mismatch can be inspected without bespoke helper code
- [ ] Claude-style temporary ROI/measurement helper is replaced by the standalone path
