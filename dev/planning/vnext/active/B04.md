# B04 — Stage-agnostic DrawingSession

Status: ACTIVE
Activated: 2026-08-30
Baseline: `25ec4544e86fe37fc28d64575df145a1b711d63a` (frozen R23 reference)

## Responsibility

Deliver the minimal vNext session facade over shared R23 drawing capabilities:
one authoritative history, stage-free drawing mutations, current-state-bound
inspection, and portable checkpoint/resume.

## Why this slice now

- Impact (1–5): 5 — the vNext lifecycle has no executable session boundary yet.
- Uncertainty (1–5): 4 — the adapter must preserve history/render parity without
  importing the R23 stage workflow.
- Reusability (1–5): 5 — B05/B06 and later slices depend on this ownership boundary.
- Dependency override: B02+B03 is CLOSED and supplies the single InspectionSheet path.

## Inputs

- A subject image with a stable SHA-256 identity.
- Agent-authored stage-free drawing actions.
- Shared `StrokeIR`, `CanvasHistory`, action transaction, pencil material, and renderer capabilities.
- B02+B03 `InspectionSheet` and explicit subject-space `Registration`.

## Outputs

- `img2drawing.vnext.DrawingSession` facade.
- Current stage-free `StrokeIR` projection and `drawing_state_hash`.
- Atomic `inspect()` artifacts bound to the same snapshot used for rendering.
- Portable vNext checkpoint with history, subject identity, state digest, renderer identity,
  and relative artifact references.

## Frozen contracts touched

- Public vNext operations do not accept, branch on, or require `P1`–`P6`.
- Any legacy stage label is opaque compatibility provenance inside the adapter only.
- One history is authoritative; snapshots are read-only projections.
- `inspect()` renders and hashes the same authoritative snapshot atomically. It does not
  accept an arbitrary drawing path or caller-supplied state hash on the normal vNext path.
- Mutations append through the shared transaction/history path and checkpoint atomically.
- Checkpoint/resume preserves subject binding, cursor/history, current-state digest, and
  renderer identity without R23 stage/review manifests.

## Explicit non-goals

- B05 observation/construction grammar.
- B06 correction prioritization or correction memory policy.
- B07 evidence compaction and all later slices.
- R23 stage progression, stage manifests, visual PASS/FAIL, or review schemas.
- A second renderer, inspection implementation, or runtime tree.

## Definition of Closed

- [ ] A 10-stroke drawing can be created, modified, and resumed without stage input.
- [ ] `draw`, `draw_many`, `replace_stroke`, `replace_segment`, `soft_lift`, and
      `delete_stroke` preserve shared renderer/material parity.
- [ ] Every accepted mutation has an atomic checkpoint boundary.
- [ ] `inspect()` binds one current snapshot to its state hash and rendered raster.
- [ ] No vNext normal-path import requires stage modules or `run.py`.
- [ ] Tests focus on drawing-state invariants, not workflow state-machine gates.
- [ ] Portable checkpoint/resume retains inspection continuity or explicitly preserves
      the inspection history needed by the contract.
- [ ] Documentation, duplicate-path, orphan-path, and integration checks pass.
- [ ] Context capsule is written and B05 remains SKELETON.
