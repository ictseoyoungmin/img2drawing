# B05 — Observation + Construction Grammar

Status: **ACTIVE**
Activated: 2026-08-30 by manual decision after B04 closure

## Responsibility

Make a fresh worker start a figure with a readable whole-pose construction:

`read pose → line of action → head/ribcage/pelvis mass → balance/plumb → joints/limbs`

This is a skill-side authoring grammar over the stage-free `DrawingSession`. It
is not a runtime stage machine and it does not add a second renderer,
inspection path, manifest, or visual verdict.

## Why this slice now

- Impact: 5 — the first few marks determine whether the subject is recognizable
  before later detail can hide structural drift.
- Uncertainty: 5 — the R23 record proves process coverage, not reliable initial
  whole-figure likeness.
- Reusability: 5 — the same observation and construction vocabulary should work
  for every future subject and feed B06 correction.
- Dependency override: B04 is the only active foundation; its atomic history,
  stage-free drawing, and existing inspection implementation remain authoritative.

## Inputs

- one subject image;
- a short agent-authored `PoseObservation`;
- explicit subject-space `ConstructionMark` geometry;
- optional plumb/ground guides and focused ROIs for the first inspection.

## Outputs

- `PoseObservation`, `ConstructionMark`, and `InitialConstruct` value objects;
- one `author_initial_construct()` path that observes once and commits ordered
  drawing marks through `DrawingSession.draw_many()`;
- one `inspect_initial_construct()` adapter over `DrawingSession.inspect()`;
- a real-subject dogfood showing the initial construct before correction.

## Frozen contracts touched

- B04 one-history authority, stage-free public drawing actions, checkpoint
  atomicity, subject/observation provenance, and existing inspection binding.
- Construction phase labels are authoring vocabulary only. They do not become
  public stage state or advancement gates.

## Explicit non-goals

- correction prioritization or correction memory (B06);
- contour/detail/value finish;
- automatic pose/anatomy inference or artistic scoring;
- new JSON schemas, review manifests, runtime gates, or renderer/inspection
  implementations;
- changing the frozen R23 workflow or keeping a second vNext drawing path.

## Definition of Closed

- [ ] A short pre-draw pose observation is recorded before the first marks.
- [ ] The initial construct keeps the five ordered phases legible without runtime
      stage state.
- [ ] Whole-figure macro relationships (flow, masses, balance, limbs/feet/prop)
      are visible in a real-subject dogfood, not only in unit fixtures.
- [ ] The first inspection directly compares subject and drawing with existing
      whole-view/ROI/guide evidence.
- [ ] Tests cover malformed marks, order preservation, observation provenance,
      atomic batch authoring, inspection integration, and resume continuity.
- [ ] The skill documentation makes the vNext grammar the default for new runs;
      legacy stage workflow remains compatibility-only.
- [ ] Direct visual inspection shows the construct is not a generic mannequin or
      a stick/rail placeholder. If it is, keep B05 ACTIVE or reopen the earliest
      construction premise.
