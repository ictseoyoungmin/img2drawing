# B04 — Stage-agnostic DrawingSession

Status: CLOSED
Activated: 2026-08-30
Closed: 2026-08-30
Baseline: `25ec4544e86fe37fc28d64575df145a1b711d63a` (frozen R23 reference)

## Responsibility

Deliver the minimal vNext session facade over shared R23 drawing capabilities:
one authoritative history, stage-free drawing mutations, current-state-bound
inspection, and portable checkpoint/resume.

## Delivered

- `img2drawing.vnext.DrawingSession` and the root lazy compatibility alias
  `img2drawing.DrawingSession`.
- Stage-free `create`, `resume`, `observe`, `draw`, `draw_many`, `replace_stroke`,
  `replace_segment`, `soft_lift`, `delete_stroke`, `inspect`, `checkpoint`, and
  `finish` operations.
- Shared `AgentDrawingSession`/`CanvasHistory` action and transaction substrate;
  no second drawing or renderer tree.
- Stage-free `StrokeIR` projection and B02+B03 `InspectionSheet` facade.

## Frozen contracts

- Public vNext operations do not accept, branch on, or require `P1`–`P6`.
- The legacy stage slot survives only as the opaque adapter value
  `__vnext_compat__`; public snapshots clear it and authored nested metadata remains
  part of drawing identity.
- One history is authoritative. Public `current_ir()` is a read-only stage-free
  projection; mutations append through the shared action/history path.
- Every accepted mutation writes the session checkpoint inside the same transaction;
  a checkpoint failure rolls the mutation back. `draw_many` is one atomic batch.
- `inspect()` accepts no arbitrary drawing path or caller-supplied state hash. Under
  one session lock it snapshots, renders the stage-free snapshot through the shared
  pencil-contact renderer, and passes that exact snapshot to
  `InspectionSheet.create(..., drawing_ir=snapshot)`. The resulting raster and
  `drawing_state_hash` therefore come from one authoritative state.
- Checkpoints bind subject name plus SHA-256, history/cursor/action log, current
  stage-free digest, renderer identity/version/seed domain, inspection history, and
  relative artifact references. They do not contain R23 stage/review manifests.
- Subject bytes are revalidated before checkpoint and inspection; subject mutation
  fails closed.

## Explicit non-goals kept inactive

- B05 observation/construction grammar and B06 correction prioritization/memory policy.
- R23 stage progression, stage manifests, visual PASS/FAIL, review schemas, or
  `run.py` orchestration on the vNext normal path.
- A second renderer, inspection implementation, or runtime tree.
- Visual quality judgement or automatic semantic inference.

## Known limitations

- B04 provides lifecycle and state integrity only; it does not judge likeness or
  implement the ordered construction grammar.
- `finish()` records caller metadata and checkpoint continuity; completion policy is
  intentionally deferred to the later finish slice.
- Existing R23 renderer material behavior is reused with the vNext stage-independent
  projection; R23 legacy replay remains unchanged and is not vNext PASS evidence.

## Integration notes

- B05 may consume `DrawingSession.observe()` and stage-free `draw()` without adding
  stage branches or another history authority.
- B06 may use explicit replace/segment/soft-lift provenance; it must preserve the
  one-snapshot inspection binding and must not add a second inspection path.
- B02+B03 remains the sole inspection implementation.

## Reopen conditions

- A vNext public operation gains a required stage branch or stage gate.
- A mutation can be visible in memory without a successful atomic checkpoint.
- `inspect()` can pair an arbitrary raster with an unrelated digest or mutate drawing
  geometry.
- Resume loses subject identity, history/cursor, inspection continuity, or renderer
  compatibility.
- A second co-equal session, renderer, or inspection implementation appears.
