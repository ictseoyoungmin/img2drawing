## Goal

Separate workflow semantics from the drawing runtime before B02+B03 inspection
work or B04 session work begins. This slice freezes ownership and dependency
direction; it does not implement `DrawingSession`, inspection, or runtime changes.

## WIP boundary

Only B01 is active. R23 remains frozen/reference-only. No source files under
`skills/img2drawing/src/`, no new review schema, and no B02/B04 implementation may
be added by this slice.

## Audit method

- Audit the R23 source tree at the pinned baseline. The current source tree is
  unchanged from `25ec454`.
- Trace local imports, public exports, state owners, persistence, rendering, and
  stage/review call sites.
- Classify each relevant unit as exactly one of: `reuse unchanged`, `extract
  stage-free portion`, `legacy-wrap`, or `retire`.
- Freeze only decisions that would invalidate later slices. Leave implementation
  mechanics to the slice that owns them.

## Dependency direction found

```text
R23 DrawingRun
  ├─ stages + stage-bound observation/reference
  ├─ review manifests, packets, pass memory, reopen bookkeeping
  ├─ AgentDrawingSession → DrawingAction → CanvasHistory → StrokeIR
  ├─ CanvasRuntime/Inspector → renderer
  └─ checkpoint payload → resume/review reconstruction

Stage-free capability seam for vNext
  action input → authoritative history → StrokeIR snapshot → renderer
                         ├→ read-only inspection
                         ├→ correction memory/provenance
                         └→ checkpoint/replay
```

The only state authority is the session/history path. `StrokeIR` is a derived
current-state projection. Canvas and renderer are consumers. Inspection is
read-only. The Agent owns observation, mismatch prioritization, correction choice,
and visual acceptance.

## Frozen vNext contract decisions

1. The canonical lifecycle is `create → observe → draw → inspect → correct →
   repeat → finish`; it is a conceptual contract, not an implementation in B01.
2. No vNext public operation requires, stores, or branches on `P1`–`P6`. A legacy
   stage label may remain as opaque provenance while crossing the adapter boundary.
3. `DrawingSession` owns session identity/metadata and delegates authoritative
   current drawing state to one history log. `StrokeIR` snapshots are read-only
   projections consumed by render and inspection.
4. `draw()` and `correct()` accept authored actions without stage gates. Corrections
   target explicit stroke/segment identity and append history-preserving edits;
   earlier-stage reopen bookkeeping is not required.
5. `inspect()` is read-only and returns one current-state-bound inspection product;
   it does not create stage manifests, process-closure records, or visual PASS
   decisions. B02 owns the concrete InspectionSheet shape.
6. Checkpoint persistence binds subject identity, action/history state, current-state
   digest, renderer identity/version, and portable artifact references. R23
   `stage_registry`, `progress`, review manifests, and reopen maps remain adapter-
   only data.
7. Replay is cursor/history based and renderer-deterministic. Stage-labelled
   timelapse modes remain R23 compatibility behavior, not the vNext contract.
8. The shared implementation path is singular. R23 compatibility may wrap or read
   shared capabilities, but vNext and R23 are not two co-equal production trees.
