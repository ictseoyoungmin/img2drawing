# Mixed-media 2048-square stress evidence

This public fixture contains no observed reference, image, or private geometry.
The protocol and script are committed before execution. Run in isolated Python
environments with the same pinned dependency versions and separate fresh output
directories. The workflow installs the verified official v1.3.0 wheel and the
current development wheel; both execute the same graphite fixture. It also runs
the current ink fixture. Graphite uses outlines for the area and tone geometry,
so material comparisons are not equal-appearance comparisons.

The exact mechanical gates in protocol.json are independent of speed. Wall time,
CPU, peak RSS and artifact size are measurements of this workload and environment,
not universal acceptance thresholds. compare.py requires the retained legacy
graphite profile, action/state/final digests and every sampled RGB hash to match.
The final encoded GIF must pass the existing tolerance; its byte identity is
reported, not a cross-platform gate.

Use the dedicated Mixed media stress evidence workflow (PR paths restricted to
this harness, or manual dispatch after promotion). No full stress execution is
added to the ordinary test suite. Store only small metrics/seals, not generated
checkpoints, frame packs, GIFs or images in Git. Private session tests remain
local. The workflow derives the candidate package version from the checked-out
source; the official v1.3.0 baseline wheel and sealed protocol remain fixed.
